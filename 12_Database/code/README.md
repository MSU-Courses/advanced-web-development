# Примеры к главе "Работа с базой данных в PHP"

В папке лежат все примеры главы в виде готовых скриптов. Примеры работают с базой данных `test_app` на локальном сервере MySQL (пользователь `root` без пароля, как в XAMPP). Соединение для примеров 00 и 03-14 открывает файл `db.php`. Сначала нужно создать базу `test_app` и выполнить `php 00_reset.php`: скрипт пересоздаёт таблицу `users` из `schema.sql` с тремя исходными строками. Каждый пример запускают из терминала командой `php имя_файла.php`. Выводы в главе получены, когда каждый пример запускали сразу после `00_reset.php`. Значения, которые в главе приходят из `$_GET`, при запуске из терминала берутся из значения по умолчанию после `??`. Ни один пример не зацикливается.

Папка `minishop` - проект из раздела "ООП-подход". Перед запуском нужно скопировать `config/config.sample.php` в `config/config.php`, создать базу `minishop`, выполнить в ней `schema.sql` и затем `composer dump-autoload` и `php run.php`.
