## Ретроспектива

В предыдущей главе наши программы делали ровно одно: выводили заранее записанные значения. Такой код всегда выдаёт один и тот же результат, а web-приложение по своей природе должно вести себя иначе. Товар либо есть на складе, либо нет. Цена может быть со скидкой, а может быть без. Список товаров нужно вывести не один раз, а столько раз, сколько товаров в каталоге.

Чтобы программа могла принимать решения, ей нужны две вещи. Во-первых, понимание того, с какими данными она работает: число это или текст, пустое значение или ноль. Во-вторых, конструкции, позволяющие выбирать между вариантами и повторять действия.

Эта глава закрывает обе темы. Сначала разберём типы данных и правила их преобразования, затем операторы, и в конце управляющие конструкции. Порядок именно такой не случайно: условие `if ($price > 0)` невозможно понять, не зная, что PHP делает со значениями разных типов при сравнении.

## Типы данных

### Динамическая типизация

**Тип данных** - характеристика значения, определяющая множество допустимых значений и набор операций, которые над ними можно выполнять.

Простыми словами - тип данных определяет:

1. Что за значение хранится в переменной;
2. Какие операции с ним можно выполнять.

PHP использует динамическую типизацию: тип не объявляется заранее, а определяется по присвоенному значению.

```php
<?php

$name = 'Alice';     // string
$age = 30;           // int
$height = 1.75;      // float
$isStudent = true;   // bool
```

Ключевой момент: типы в PHP существуют и работают, просто их не нужно указывать. Это не то же самое, что "_типов нет_". Значение `'30'` (строка) и значение `30` (целое число) ведут себя по-разному, и большинство неожиданных результатов у начинающих связано именно с этой разницей.

Тип переменной может измениться в ходе выполнения программы:

```php
<?php

$value = 10;
var_dump($value);   // int(10)

$value = 'десять';
var_dump($value);   // string(12) "десять"
```

Язык это позволяет, но пользоваться такой возможностью без необходимости не стоит. Переменная, которая по ходу программы меняет смысл, читается плохо.

### Как узнать тип значения?

Чтобы узнать 3 значения переменной, можно использовать несколько способов:

- Использовать функцию `var_dump()`;
- Использовать функцию `gettype()`;
- Использовать функцию `is_*()` (например, `is_int()`, `is_string()` и т.д.);

Функция `var_dump()` выводит тип и значение. Это основной инструмент отладки.

_Синтаксис_

```php
var_dump(mixed ...$values): void
```

- `...$values` - одно или несколько значений любого типа.
- Ничего не возвращает, а сразу печатает результат.

```php
<?php

var_dump('Alice');   // string(5) "Alice"
var_dump(30);        // int(30)
var_dump(1.75);      // float(1.75)
var_dump(true);      // bool(true)
var_dump(null);      // NULL
```

Функция `gettype()` возвращает название типа строкой.

_Синтаксис_

```php
gettype(mixed $value): string
```

- `$value` - проверяемое значение.
- Возвращает одну из строк: `integer`, `double`, `string`, `boolean`, `array`, `object`, `NULL`.

> [!NOTE]
>
> Обратите внимание на расхождение: тип называется `int`, а `gettype()` возвращает `integer`; тип `float` возвращается как `double`. Это наследие ранних версий языка.

```php
<?php

echo gettype(30);      // integer
echo gettype('Alice'); // string
```

Семейство функций `is_*()` проверяет принадлежность значения типу.

_Синтаксис_

```php
is_int(mixed $value): bool
is_float(mixed $value): bool
is_string(mixed $value): bool
is_bool(mixed $value): bool
is_null(mixed $value): bool
```

- `$value` - проверяемое значение.
- Возвращает `true`, если значение принадлежит указанному типу, иначе `false`.

```php
<?php

$age = 30;

var_dump(is_int($age));      // bool(true)
var_dump(is_string($age));   // bool(false)
```

> [!NOTE]
> Если вывести результат `is_int()` через `echo`, вы увидите `1` вместо `true` и пустую строку вместо `false`. Причина в том, что `echo` приводит логическое значение к строке. Для проверок используйте `var_dump()`.

### Какие типы существуют

```text
Типы данных PHP
│
├── Скалярные (одно значение)
│     ├── int     целое число
│     ├── float   дробное число
│     ├── string  строка
│     └── bool    логическое значение
│
├── Составные (набор значений)
│     ├── array   массив
│     └── object  объект
│
└── Специальные
      ├── null      отсутствие значения
      └── resource  ссылка на внешний ресурс
```

_Схема 3.1. Типы данных PHP_

В данной главе мы разберем различные только скалярные типы данных и `null`. Массивы, объекты и работа с ресурсами будут темами следующих глав.

### Тип `int`

**int** - целое число без дробной части: положительное, отрицательное или ноль.

Диапазон зависит от разрядности системы. На современных 64-битных системах это значения примерно от минус до плюс девяти квинтиллионов, а точные границы доступны через константы:

```php
<?php

echo PHP_INT_MAX;    // 9223372036854775807
echo PHP_INT_MIN;    // -9223372036854775808
echo PHP_INT_SIZE;   // 8 (размер в байтах)
```

При выходе за границу PHP не сообщает об ошибке, а молча превращает значение в `float`:

```php
<?php

var_dump(PHP_INT_MAX + 1);   // float(9.2233720368548E+18)
```

Целые числа записываются не только в десятичной системе:

| Система           | Префикс      | Пример        | Значение |
| ----------------- | ------------ | ------------- | -------- |
| Десятичная        | нет          | `42`          | 42       |
| Двоичная          | `0b`         | `0b101010`    | 42       |
| Восьмеричная      | `0o` или `0` | `0o52`, `052` | 42       |
| Шестнадцатеричная | `0x`         | `0x2A`        | 42       |

Для читаемости больших чисел допустим символ подчёркивания, который не влияет на значение:

```php
<?php

$price = 1_299_000;
var_dump($price);   // int(1299000)
```

### Тип `float`

**float** - число с дробной частью, хранимое по стандарту IEEE 754 с двойной точностью.

```php
<?php

$price = 149.99;
$exponential = 1.5e3;

var_dump($exponential);      // float(1500)
var_dump(PHP_FLOAT_MAX);     // float(1.7976931348623157E+308)
var_dump(PHP_FLOAT_MIN);     // float(2.2250738585072014E-308)
```

Двоичное представление не способно точно записать многие десятичные дроби, и отсюда следует правило, которое нужно запомнить сразу:

```php
<?php

var_dump(0.1 + 0.2);            // float(0.30000000000000004)
var_dump(0.1 + 0.2 == 0.3);     // bool(false)
```

> [!WARNING]
>
> Дробные числа нельзя сравнивать на точное равенство. Результат `0.1 + 0.2 == 0.3` равен `false` не из-за ошибки в PHP, а из-за самого способа хранения дробных чисел в двоичном виде.

Сравнивать следует используя функцию `abs()`, которая возвращает модуль числа.

```php
<?php

$a = 0.1 + 0.2;
$b = 0.3;

var_dump(abs($a - $b) < PHP_FLOAT_EPSILON);   // bool(true)
```

Константа `PHP_FLOAT_EPSILON` - наименьшее положительное число, такое что `1.0 + PHP_FLOAT_EPSILON` отличается от `1.0`. Используется для сравнения чисел с плавающей запятой с учетом возможных погрешностей.

Отсюда же следует практическое правило работы с деньгами. Суммы обычно хранят в минимальных единицах, то есть целым числом копеек или банов, а не дробным числом лей. Тогда все вычисления остаются целочисленными и точными. Хотя все зависит от конкретной задачи, есть библиотеки для работы с денежными суммами, которые учитывают эти особенности.

### Тип `string`

**string** - последовательность символов.

Три формы записи строк были разобраны в предыдущей главе, повторим кратко.

```php
<?php

$name = 'Alice';

echo 'Привет, $name';   // Привет, $name
echo "Привет, $name";   // Привет, Alice
```

В одинарных кавычках текст берётся буквально. В двойных работают подстановка переменных и управляющие последовательности `\n`, `\t`, `\\`, `\"`.

Для многострочного текста есть две дополнительные формы: _Heredoc_ ведёт себя как двойные кавычки, _Nowdoc_ как одинарные.

_Синтаксис_

```php
$переменная = <<<ИДЕНТИФИКАТОР
текст
ИДЕНТИФИКАТОР;

$переменная = <<<'ИДЕНТИФИКАТОР'
текст
ИДЕНТИФИКАТОР;
```

- `ИДЕНТИФИКАТОР` - произвольное имя, одинаковое в начале и в конце.
- Кавычки вокруг идентификатора в открывающей строке переключают режим: без кавычек Heredoc с подстановкой переменных, в одинарных кавычках Nowdoc без подстановки.

```php
<?php

$name = 'Alice';

$heredoc = <<<TEXT
Здравствуйте, $name!
Ваш заказ принят.
TEXT;

$nowdoc = <<<'TEXT'
Здесь $name останется текстом.
TEXT;
```

Идентификатор после `<<<` может быть любым, но открывающий и закрывающий должны совпадать, а закрывающий должен стоять в начале своей строки.

> [!TIP]
>
> Heredoc удобен для писем и больших блоков текста. Для обычных строк он избыточен: двойных и одинарных кавычек хватает почти всегда.

### Тип `bool`

**bool** - логический тип с двумя возможными значениями: `true` и `false`.

```php
<?php

$inStock = true;
$isDeleted = false;

var_dump($inStock);   // bool(true)
```

Ключевые слова `true` и `false` нечувствительны к регистру, но записывать их принято строчными буквами.

Важная деталь при выводе: `echo true` печатает `1`, а `echo false` печатает пустую строку. Поэтому логические значения выводят не напрямую, а через условие или `var_dump()`.

### Значение `null`

**null** - специальное значение, означающее отсутствие значения.

```php
<?php

$discount = null;

var_dump($discount);   // NULL
var_dump(is_null($discount));   // bool(true)
```

Разница между `null`, нулём и пустой строкой существенная, хотя в условиях все три ведут себя одинаково:

| Значение | Смысл                                   |
| -------- | --------------------------------------- |
| `null`   | Значения нет вообще                     |
| `0`      | Значение есть и равно нулю              |
| `''`     | Значение есть и является пустым текстом |

Скидки нет, скидка равна нулю и поле скидки пустое это три разные ситуации. Смешивать их не стоит.

> [!NOTE]
>
> Начиная с PHP 7 типы можно указывать явно: в параметрах и возвращаемых значениях функций, в свойствах классов. Есть и комбинированные типы вида `int|false`. К этой теме мы вернёмся, когда дойдём до функций и классов, потому что без них объявлять типы негде.

## Преобразование типов

### Зачем это нужно

Данные, приходящие в web-приложение, почти всегда являются строками. Пользователь ввёл в форму возраст, и PHP получит не число `21`, а строку `'21'`. То же касается параметров в адресной строке и значений из cookies.

Дальше с этим значением нужно что-то делать:

- Сравнить,
- Сложить,
- Проверить.

В данном случае преобразование типов позволяет PHP корректно работать с данными, даже если они приходят в виде строк.

**Преобразование типов** - приведение значения одного типа к другому.

Преобразования типов делится на явное и неявное.

- **Явное преобразование** выполняется с помощью операции или функции приведения типа, например `(int)$value`.
- **Неявное преобразование** происходит автоматически, когда PHP ожидает значение определённого типа.

Оба вида работают по одним и тем же правилам, различается только то, кто их запускает. Поэтому дальше сначала разбираются сами правила, затем инструменты явного преобразования и в конце ситуации, где PHP применяет их самостоятельно.

### Правила преобразования

#### Преобразование в `bool`

Любое значение в PHP можно привести к булеву типу. Есть всего 7 знасений, которые приводятся к `false`:

| Значение                      | Тип    |
| ----------------------------- | ------ |
| `false`                       | bool   |
| `0`                           | int    |
| `0.0`, `-0.0`                 | float  |
| `''` (пустая строка)          | string |
| `'0'` (строка из одного нуля) | string |
| `[]` (пустой массив)          | array  |
| `null`                        | null   |

Всё остальное приводится к `true`. Список стоит запомнить целиком: он короткий, а работает в каждом условии программы.

```php
<?php

var_dump((bool) '0');       // bool(false)
var_dump((bool) '0.0');     // bool(true)
var_dump((bool) 'false');   // bool(true)
var_dump((bool) ' ');       // bool(true)
var_dump((bool) -1);        // bool(true)
```

#### Преобразование в `int`

| Исходный тип | Правило                                                                                                 |
| ------------ | ------------------------------------------------------------------------------------------------------- |
| `float`      | Дробная часть отбрасывается, округления нет: `19.99` даёт `19`, а `-19.99` даёт `-19`                   |
| `bool`       | `true` даёт `1`, `false` даёт `0`                                                                       |
| `null`       | Даёт `0`                                                                                                |
| `string`     | Берётся числовая часть с начала строки, остальное отбрасывается; если числа в начале нет, результат `0` |

Правило для строк стоит разобрать подробнее. PHP читает строку слева направо, пропуская ведущие пробелы, и забирает знак, цифры, точку и экспоненциальную часть. Как только встречается символ, не подходящий под запись числа, чтение прекращается.

```php
<?php

var_dump((int) '42');           // int(42)
var_dump((int) ' 42');          // int(42), ведущий пробел допустим
var_dump((int) '42abc');        // int(42)
var_dump((int) 'abc42');        // int(0), число не в начале
var_dump((int) '3.99');         // int(3), сначала строка читается как 3.99, затем отбрасывается дробная часть
var_dump((int) '1e3');          // int(1000), экспоненциальная запись распознаётся
var_dump((int) '0x1A');         // int(0), шестнадцатеричные строки не распознаются
var_dump((int) '007');          // int(7)
```

Предпоследняя строка часто становится неожиданностью: литерал `0x1A` в коде означает число 42, но строка `'0x1A'`, пришедшая от пользователя, превращается в ноль.

#### Преобразование в `float`

Правила те же, что и для `int`, с одним отличием: дробная часть сохраняется.

```php
<?php

var_dump((float) '3.99');      // float(3.99)
var_dump((float) '19.99abc');  // float(19.99)
var_dump((float) 'abc');       // float(0)
var_dump((float) true);        // float(1)
var_dump((float) null);        // float(0)
```

#### Преобразование в `string`

| Исходный тип | Правило                                                                           |
| ------------ | --------------------------------------------------------------------------------- |
| `int`        | Десятичная запись числа                                                           |
| `float`      | Десятичная запись; очень большие и очень малые числа записываются экспоненциально |
| `bool`       | `true` даёт `'1'`, `false` даёт пустую строку `''`                                |
| `null`       | Даёт пустую строку `''`                                                           |

```php
<?php

var_dump((string) 42);        // string(2) "42"
var_dump((string) 19.99);     // string(5) "19.99"
var_dump((string) 1.0);       // string(1) "1", дробная часть исчезла
var_dump((string) 1e20);      // string(7) "1.0E+20"
var_dump((string) true);      // string(1) "1"
var_dump((string) false);     // string(0) ""
var_dump((string) null);      // string(0) ""
```

Две последние строки объясняют поведение, с которым вы уже сталкивались в предыдущей главе: `echo false` ничего не печатает, потому что `false` превращается в пустую строку, а не в слово `false`.

#### Сводная таблица

Все четыре правила на одних и тех же примерах:

| Значение  | `(int)` | `(float)` | `(string)` | `(bool)` |
| --------- | ------- | --------- | ---------- | -------- |
| `19.99`   | `19`    | `19.99`   | `'19.99'`  | `true`   |
| `-19.99`  | `-19`   | `-19.99`  | `'-19.99'` | `true`   |
| `0`       | `0`     | `0.0`     | `'0'`      | `false`  |
| `true`    | `1`     | `1.0`     | `'1'`      | `true`   |
| `false`   | `0`     | `0.0`     | `''`       | `false`  |
| `null`    | `0`     | `0.0`     | `''`       | `false`  |
| `'42'`    | `42`    | `42.0`    | `'42'`     | `true`   |
| `'42abc'` | `42`    | `42.0`    | `'42abc'`  | `true`   |
| `'abc'`   | `0`     | `0.0`     | `'abc'`    | `true`   |
| `'0'`     | `0`     | `0.0`     | `'0'`      | `false`  |
| `'0.0'`   | `0`     | `0.0`     | `'0.0'`    | `true`   |
| `''`      | `0`     | `0.0`     | `''`       | `false`  |

### Явное преобразование

Есть два основных способа явного преобразования типов:

- Оператор приведения типа;
- Функции приведения типа.

#### Оператор приведения типа

_Синтаксис_

```php
(тип) выражение
```

- `тип` - один из вариантов: `int`, `float`, `string`, `bool`, `array`, `object`.
- Возвращает новое значение указанного типа, исходная переменная не изменяется.

_Пример_

```php
<?php

$input = '42';

var_dump((int) $input);      // int(42)
var_dump((float) $input);    // float(42)
var_dump((string) $input);   // string(2) "42"
var_dump((bool) $input);     // bool(true)
```

### Функции приведения типа

_Синтаксис_

```php
intval(mixed $value, int $base = 10): int
floatval(mixed $value): float
strval(mixed $value): string
boolval(mixed $value): bool
```

- `$value` - преобразуемое значение.
- `$base` - система счисления для строк, по умолчанию десятичная. Работает только тогда, когда `$value` является строкой.
- Возвращают новое значение соответствующего типа.

_Пример_

```php
<?php

$price = '19.99';

var_dump(intval($price));     // int(19)
var_dump(floatval($price));   // float(19.99)
```

Параметр `$base` решает ровно ту задачу, которая не решается приведением `(int)`:

```php
<?php

var_dump((int) '0x1A');          // int(0)
var_dump(intval('0x1A', 16));    // int(26)
var_dump(intval('101', 2));      // int(5)
```

Третий инструмент - функция `settype()`, которая меняет тип самой переменной, а не возвращает новое значение.

_Синтаксис_

```php
settype(mixed &$var, string $type): bool
```

- `&$var` - переменная, тип которой будет изменён. Знак `&` означает, что функция изменяет саму переданную переменную.
- `$type` - название целевого типа строкой: `'int'`, `'float'`, `'string'`, `'bool'`.
- Возвращает `true` при успешном преобразовании.

В современном коде `settype()` используется редко: приведение `(int)` короче и не меняет исходную переменную незаметно для читателя.

### Неявное преобразование

Неявное преобразование выполняется по тем же правилам, но без участия разработчика. PHP делает это в четырёх ситуациях:

- В арифметических операциях;
- В логических операциях;
- При сравнении значений;
- При передаче аргументов в функции.

#### В арифметических операциях

При арифметических операциях, когда операнды имеют разные типы, PHP приводит их к числу.

> [!NOTE]
>
> Здесь правило для строк работает не полностью: молча преобразуются только полностью числовые строки, а остальные случаи сопровождаются предупреждением или ошибкой.

Случай первый: строка полностью числовая. Преобразование выполняется без предупреждений.

```php
<?php

var_dump('10' + 5);   // int(15)
```

Случай второй: строка начинается с числа. PHP использует начальную часть и выдаёт предупреждение.

```php
<?php

var_dump('10 apples' + 5);   // int(15)
// Warning: A non-numeric value encountered
```

Случай третий: строка не начинается с числа. PHP 8 прекращает выполнение с ошибкой.

```php
<?php

var_dump('apples' + 5);
// Fatal error: Uncaught TypeError: Unsupported operand types: string + int
```

> [!IMPORTANT]
>
> Третий случай в PHP 7 работал иначе: там выводилось предупреждение, а результат считался равным нулю. В PHP 8 это ошибка, останавливающая скрипт. Об этом стоит помнить, читая старые учебники и старый код.

Обратите внимание на разницу с явным приведением. Выражение `(int) 'apples'` даёт `0` без единого сообщения, а `'apples' + 5` останавливает программу. Одно и то же значение, разные последствия.

#### В логическом контексте

В условии `if`, в цикле `while`, в тернарном операторе и в логических операциях значение приводится к `bool` по правилам преобразования в логический тип.

```php
<?php

$input = '0';

if ($input) {
    echo 'Не выполнится: строка "0" ложна';
}
```

#### В строковом контексте

При выводе через `echo` и при _конкатенации_ значение приводится к `string`.

```php
<?php

$count = 5;
$isActive = true;

echo 'Товаров: ' . $count;      // Товаров: 5
echo 'Активен: ' . $isActive;   // Активен: 1
```

#### При сравнении

Оператор `==` приводит операнды к общему типу перед сравнением, а `===` этого не делает. Мы рассмотрим эти правила подробнее в следующих разделах.

### Как правильно проверять пользовательский ввод

Так как явное преобразование не всегда может защитить от некорректного ввода, рекомендуется использовать функции проверки и фильтрации данных.

Для числовых строк есть функция `is_numeric()`:

_Синтаксис_

```php
is_numeric(mixed $value): bool
```

- `$value` - проверяемое значение.
- Возвращает `true`, если значение является числом или строкой, целиком представляющей число. Строка `'19.99'` проходит проверку, строка `'19 лей'` не проходит.

_Пример_

```php
<?php

$input = '19.99';

if (is_numeric($input)) {
    $price = (float) $input;
    echo 'Цена: ' . $price;
} else {
    echo 'Введите корректное число';
}
```

Порядок действий здесь важен: _сначала проверка, потом преобразование, потом использование_. Этот же порядок мы будем применять к данным формы, когда дойдём до их обработки.

## Операторы

**Оператор** - символ или сочетание символов, обозначающее операцию над одним или несколькими значениями.

### Приоритет операторов

**Приоритет операторов** - правила, определяющие порядок вычисления частей выражения.

Полная таблица приоритетов есть в документации[^1], а на практике достаточно помнить верхнюю часть порядка:

```text
1. ()                    скобки
2. ++  --  (int)  !      унарные операции
3. **                    возведение в степень
4. *  /  %               умножение и деление
5. +  -                  сложение и вычитание
6. .                     конкатенация
7. <  <=  >  >=          сравнение
8. ==  !=  ===  !==      проверка равенства
9. &&                    логическое И
10. ||                   логическое ИЛИ
11. =  +=  .=            присваивание
12. and  xor  or         словесные логические операции
```

Обратите внимание на позиции 5 и 6. В PHP 8 конкатенация имеет более низкий приоритет, чем сложение, и это изменение по сравнению с PHP 7:

```php
<?php

echo 'Цена: ' . 5 + 3;   // Цена: 8
```

Сначала выполняется `5 + 3`, затем результат приклеивается к строке. В PHP 7 то же выражение приводило к ошибке, потому что сначала выполнялась конкатенация.

Универсальный совет здесь один: если есть малейшее сомнение, _ставьте скобки_. Выражение `'Цена: ' . (5 + 3)` понятно всем и не зависит от версии языка.

### Арифметические операторы

| Оператор | Операция             | Пример   | Результат |
| -------- | -------------------- | -------- | --------- |
| `+`      | Сложение             | `7 + 2`  | `9`       |
| `-`      | Вычитание            | `7 - 2`  | `5`       |
| `*`      | Умножение            | `7 * 2`  | `14`      |
| `/`      | Деление              | `7 / 2`  | `3.5`     |
| `%`      | Остаток от деления   | `7 % 2`  | `1`       |
| `**`     | Возведение в степень | `7 ** 2` | `49`      |

Две особенности деления.

Оператор `/` возвращает `float`, если деление неточное, и `int`, если результат целый. Для целочисленного деления есть функция `intdiv()`.

_Синтаксис_

```php
intdiv(int $num1, int $num2): int
```

- `$num1` - делимое.
- `$num2` - делитель.
- Возвращает целую часть частного, дробная часть отбрасывается. При нулевом делителе выбрасывает `DivisionByZeroError`.

_Пример_

```php
<?php

var_dump(10 / 3);        // float(3.3333333333333335)
var_dump(10 / 2);        // int(5)
var_dump(intdiv(10, 3)); // int(3)
var_dump(10 % 3);        // int(1)
```

Деление на ноль в PHP 8 порождает ошибку `DivisionByZeroError`, а не предупреждение:

```php
<?php

var_dump(10 / 0);
// Fatal error: Uncaught DivisionByZeroError: Division by zero
```

Значит, делитель нужно проверять заранее:

```php
<?php

$total = 250;
$count = 0;

if ($count > 0) {
    echo 'Средняя цена: ' . ($total / $count);
} else {
    echo 'Товаров нет';
}
```

Оператор `**` правоассоциативен, то есть вычисляется справа налево: `2 ** 3 ** 2` равно `2 ** 9`, то есть `512`, а не `64`.

### Операторы присваивания

| Оператор | Запись      | Эквивалент      |
| -------- | ----------- | --------------- |
| `=`      | `$x = 5`    | Присваивание    |
| `+=`     | `$x += 5`   | `$x = $x + 5`   |
| `-=`     | `$x -= 5`   | `$x = $x - 5`   |
| `*=`     | `$x *= 5`   | `$x = $x * 5`   |
| `/=`     | `$x /= 5`   | `$x = $x / 5`   |
| `%=`     | `$x %= 5`   | `$x = $x % 5`   |
| `.=`     | `$x .= '!'` | `$x = $x . '!'` |

Оператор `.=` встречается особенно часто при постепенном накоплении текста:

```php
<?php

$html = '<ul>';
$html .= '<li>Ноутбук</li>';
$html .= '<li>Мышь</li>';
$html .= '</ul>';

echo $html;
```

### Инкремент и декремент

Операторы `++` и `--` изменяют значение на единицу. Форма записи определяет, что вернётся в выражении.

| Запись | Название              | Поведение                                      |
| ------ | --------------------- | ---------------------------------------------- |
| `$x++` | Постфиксный инкремент | Возвращает текущее значение, затем увеличивает |
| `++$x` | Префиксный инкремент  | Увеличивает, затем возвращает новое значение   |
| `$x--` | Постфиксный декремент | Возвращает текущее значение, затем уменьшает   |
| `--$x` | Префиксный декремент  | Уменьшает, затем возвращает новое значение     |

```php
<?php

$x = 5;
var_dump($x++);   // int(5), после этого $x равно 6
var_dump($x);     // int(6)

$y = 5;
var_dump(++$y);   // int(6)
```

Когда результат выражения не используется, а нужно просто увеличить счётчик, разницы между формами нет. Именно так `$i++` применяется в циклах.

### Операторы сравнения

| Оператор             | Значение                                           |
| -------------------- | -------------------------------------------------- |
| `==`                 | Равно по значению, с приведением типов             |
| `!=` или `<>`        | Не равно по значению                               |
| `===`                | Равно по значению и по типу                        |
| `!==`                | Не равно по значению или по типу                   |
| `<`, `>`, `<=`, `>=` | Меньше, больше, меньше или равно, больше или равно |
| `<=>`                | Сравнение с тремя исходами                         |

Разница между `==` и `===` заслуживает отдельного разбора, потому что именно здесь возникает большинство трудноуловимых ошибок.

Оператор `==` перед сравнением приводит операнды к общему типу:

```php
<?php

var_dump('5' == 5);        // bool(true)
var_dump('0' == false);    // bool(true)
var_dump(null == false);   // bool(true)
var_dump('1e2' == '100');  // bool(true)
```

Последняя строка показывает суть проблемы: две разные строки оказались равны, потому что обе выглядят как числа и были сравнены как числа.

Оператор `===` сравнивает и значение, и тип, поэтому такие ошибки не происходят:

```php
<?php

var_dump('5' === 5);       // bool(false)
var_dump('5' === '5');     // bool(true)
```

> [!IMPORTANT]
>
> В PHP 8 правила нестрогого сравнения строки с числом изменились. Раньше `'' == 0` и `'abc' == 0` давали `true`, теперь оба выражения дают `false`. Нечисловая строка больше не превращается в ноль, вместо этого число приводится к строке.

Практическое правило простое: по умолчанию используйте `===` и `!==`. Если получаете данные из внешних источников, то сначала приводите их к нужному типу, а затем сравнивайте с помощью строгих операторов.

Несколько характерных пар и их результат в PHP 8:

| Выражение       | `==`    | `===`   |
| --------------- | ------- | ------- |
| `0 == ''`       | `false` | `false` |
| `0 == '0'`      | `true`  | `false` |
| `0 == 'abc'`    | `false` | `false` |
| `0 == null`     | `true`  | `false` |
| `null == ''`    | `true`  | `false` |
| `null == false` | `true`  | `false` |
| `'1' == '01'`   | `true`  | `false` |
| `100 == '1e2'`  | `true`  | `false` |
| `true == 'abc'` | `true`  | `false` |

Сравнение строк работает по-разному в зависимости от их содержимого. Две числовые строки сравниваются как числа, все остальные посимвольно по кодам символов:

```php
<?php

var_dump('10' > '9');        // bool(true), сравнение как чисел
var_dump('abc' < 'abd');     // bool(true), посимвольно
var_dump('Apple' < 'apple'); // bool(true), заглавные буквы идут раньше строчных
```

В PHP также есть оператор `<=>` - **spaceship-оператор**, который возвращает -1, 0 или 1. Правила следующие:

1. Если левый операнд меньше правого, возвращается `-1`.
2. Если левый операнд равен правому, возвращается `0`.
3. Если левый операнд больше правого, возвращается `1`.

```php
<?php

var_dump(1 <=> 2); // int(-1)
var_dump(2 <=> 2); // int(0)
var_dump(3 <=> 2); // int(1)
```

Самостоятельно он используется редко, но незаменим при сортировке, к которой мы вернёмся в главе о массивах.

### Логические операторы

| Оператор | Значение        | Результат                                 |
| -------- | --------------- | ----------------------------------------- |
| `&&`     | И               | `true`, если оба операнда истинны         |
| `\|\|`   | ИЛИ             | `true`, если хотя бы один операнд истинен |
| `!`      | НЕ              | Обратное значение                         |
| `xor`    | Исключающее ИЛИ | `true`, если истинен ровно один операнд   |

```php
<?php

$age = 20;
$hasTicket = true;

if ($age >= 18 && $hasTicket) {
    echo 'Проход разрешён';
}
```

У операторов `&&` и `||` есть важное свойство: **короткое замыкание** - вычисление прекращается, как только результат становится известен.

Например, в выражении `$a && $b` если `$a` равно `false`, то `$b` даже не будет вычисляться, так как результат всего выражения уже известен.

Аналогично, в выражении `$a || $b` если `$a` равно `true`, то `$b` даже не будет вычисляться, так как результат всего выражения уже известен - `true`.

### Оператор подавления ошибок

Оператор `@` перед выражением скрывает сообщения об ошибках, возникшие при его вычислении:

```php
<?php

$content = @file_get_contents('nonexistent.txt');
```

> [!WARNING]
>
> Оператор `@` не решает проблему, а прячет её. Скрипт продолжит работу с некорректными данными, а причину сбоя вы не увидите ни на экране, ни в журнале. Вместо подавления проверяйте условия заранее или обрабатывайте ошибки явно, о чём пойдёт речь в главе об исключениях.

## Условные конструкции

### Конструкция if, elseif, else

**Условная конструкция** - управляющая конструкция, выполняющая блок кода в зависимости от истинности условия.

_Синтаксис_

```php
<?php

if (условие) {
    // выполняется, если условие истинно
} elseif (другое_условие) {
    // выполняется, если первое ложно, а это истинно
} else {
    // выполняется, если все условия ложны
}
```

- `условие` - любое выражение, результат которого приводится к `bool`.
- Блоков `elseif` может быть сколько угодно, блок `else` не обязателен.
- Ветка `else` не имеет собственного условия и выполняется, когда ложны все предыдущие.

Проверка идёт сверху вниз и останавливается на первом истинном условии. Остальные ветки не проверяются вообще.

```php
<?php

$stock = 3;

if ($stock === 0) {
    echo 'Нет в наличии';
} elseif ($stock < 5) {
    echo 'Осталось мало: ' . $stock;
} else {
    echo 'В наличии';
}
```

Веток `elseif` может быть сколько угодно, а `else` не обязателен. Фигурные скобки формально можно опускать для одной инструкции, но делать этого не стоит: код с ними безопаснее при последующих правках.

### Ранний выход вместо вложенности

Вложенные условия быстро становятся нечитаемыми:

```php
<?php

$isLoggedIn = true;
$hasAccess = true;
$stock = 3;

if ($isLoggedIn) {
    if ($hasAccess) {
        if ($stock > 0) {
            echo 'Можно оформить заказ';
        }
    }
}
```

Тот же смысл выражается плоско, через проверку условий, при которых работу нужно прекратить:

```php
<?php

$isLoggedIn = true;
$hasAccess = true;
$stock = 3;

if (!$isLoggedIn) {
    echo 'Войдите в систему';
} elseif (!$hasAccess) {
    echo 'Недостаточно прав';
} elseif ($stock <= 0) {
    echo 'Товара нет в наличии';
} else {
    echo 'Можно оформить заказ';
}
```

Это можно еще более упростить, используя ранний выход из функции или скрипта вместо вложенных условий.

```php
<?php

$isLoggedIn = true;
$hasAccess = true;
$stock = 3;

if (!$isLoggedIn) {
    echo 'Войдите в систему';
    return;
}

if (!$hasAccess) {
    echo 'Недостаточно прав';
    return;
}

if ($stock <= 0) {
    echo 'Товара нет в наличии';
    return;
}

echo 'Можно оформить заказ';
```

Второй и третий вариант читается сверху вниз, каждая причина отказа видна сразу, и добавить новую проверку можно, не увеличивая глубину вложенности.

### Тернарный оператор

**Тернарный оператор** - оператор с тремя операндами, возвращающий одно из двух значений в зависимости от условия.

Мы его специально не рассмотрели в разделе с операторами, так как он чаще используется в контексте условий и управления потоком выполнения, а не как отдельный оператор.

_Синтаксис_

```php
условие ? значение_если_истина : значение_если_ложь
```

- Является выражением, то есть возвращает значение и может стоять справа от знака `=` или внутри строки.
- Обе ветви обязательны.

_Пример_

```php
<?php

$age = 20;

$status = $age >= 18 ? 'Взрослый' : 'Несовершеннолетний';
echo $status;
```

Он полезен именно там, где нужно выбрать значение, а не выполнить действие. Особенно удобен внутри разметки:

```php
<h2 class="<?= $inStock ? 'available' : 'sold-out' ?>">Товар</h2>
```

Есть сокращённая форма, оператор `?:`.

_Синтаксис_

```php
значение ?: значение_по_умолчанию
```

- Возвращает левое значение, если оно истинно, иначе правое.
- Если левое значение не определено, выдаётся предупреждение.

```php
<?php

$title = '';
echo $title ?: 'Без названия';   // Без названия
```

И отдельный оператор `??`, который проверяет не истинность, а наличие значения.

_Синтаксис_

```php
значение ?? значение_по_умолчанию
```

- Возвращает левое значение, если оно существует и не равно `null`, иначе правое.
- Не выдаёт предупреждения для несуществующей переменной, поэтому подходит для чтения внешних данных.

```php
<?php

$discount = null;
echo $discount ?? 0;   // 0
```

Разница между `?:` и `??` принципиальна.

1. Оператор `?:` сработает на любом ложном значении, включая `0` и пустую строку.
2. Оператор `??` сработает только на `null`.
3. Для данных, приходящих извне, обычно нужен `??`, и мы будем пользоваться им постоянно при чтении параметров запроса.

> [!WARNING]
>
> Вкладывать тернарные операторы друг в друга не нужно. Такая запись читается плохо, а в PHP 8 вложенность без скобок вызывает ошибку. Если вариантов больше двух, используйте `if` или `match`.

### Конструкция switch

Конструкция `switch` сравнивает одно значение с набором вариантов.

_Синтаксис_

```php
switch (выражение) {
    case значение_1:
        // инструкции
        break;
    case значение_2:
        // инструкции
        break;
    default:
        // инструкции
}
```

- `выражение` - значение, которое сравнивается с вариантами.
- `case значение` - вариант сравнения. Сравнение нестрогое, как оператором `==`.
- `break` - выход из конструкции. Без него выполнение продолжится в следующую ветку.
- `default` - ветка, выполняемая при отсутствии совпадений. Не обязательна, но располагается последней.

_Пример_

```php
<?php

$role = 'editor';

switch ($role) {
    case 'admin':
        echo 'Полный доступ';
        break;
    case 'editor':
        echo 'Редактирование материалов';
        break;
    default:
        echo 'Только чтение';
}
```

Две особенности, о которых нужно знать.

Первая: без `break` выполнение продолжается в следующую ветку. Иногда это используют намеренно, чтобы объединить варианты:

```php
<?php

$role = 'author';

switch ($role) {
    case 'editor':
    case 'author':
        echo 'Редактирование материалов';
        break;
    default:
        echo 'Только чтение';
}
```

Но гораздо чаще пропущенный `break` оказывается обычной ошибкой, которая проявляется не сразу.

Вторая: `switch` сравнивает нестрого, то есть работает как `==`.

```php
<?php

switch ('1') {
    case 1:
        echo 'Совпало';   // выполнится
        break;
}
```

### Конструкция match

В PHP 8 появилась конструкция `match`, решающая обе проблемы `switch`.

_Синтаксис_

```php
match (выражение) {
    значение_1 => результат_1,
    значение_2, значение_3 => результат_2,
    default => результат_по_умолчанию,
};
```

- `выражение` - значение для сравнения. Сравнение строгое, как оператором `===`.
- Слева от `=>` перечисляются одно или несколько значений через запятую.
- Справа от `=>` стоит выражение, значение которого станет результатом всей конструкции.
- `default` не обязателен, но при отсутствии совпадений и отсутствии `default` выбрасывается `UnhandledMatchError`.
- Конструкция является выражением и завершается точкой с запятой.

_Пример_

```php
<?php

$role = 'editor';

$message = match ($role) {
    'admin' => 'Полный доступ',
    'editor', 'author' => 'Редактирование материалов',
    default => 'Только чтение',
};

echo $message;
```

Отличия от `switch`:

| Свойство                       | `switch`         | `match`                      |
| ------------------------------ | ---------------- | ---------------------------- |
| Сравнение                      | Нестрогое (`==`) | Строгое (`===`)              |
| `break`                        | Нужен            | Не нужен                     |
| Возвращает значение            | Нет              | Да                           |
| Нет совпадений и нет `default` | Ничего не делает | Ошибка `UnhandledMatchError` |

Обратите внимание на последнюю строку таблицы. То, что выглядит как строгость, на деле удобно: незакрытый вариант обнаруживается сразу, а не превращается в тихо пропущенный случай.

Правило выбора простое. Если нужно получить значение по варианту, используйте `match`. Если нужно выполнить несколько действий в ветке, подойдёт `switch` или `if`.

## Циклы

**Цикл** - управляющая конструкция, повторяющая блок кода, пока выполняется условие.

### Цикл `while`

Цикл `while` проверяет условие перед каждым повторением.

_Синтаксис_

```php
while (условие) {
    // тело цикла
}
```

- `условие` - выражение, проверяемое перед каждым повторением и приводимое к `bool`.
- Тело выполняется, пока условие истинно. Если условие ложно изначально, тело не выполнится ни разу.

_Пример_

```php
<?php

$counter = 1;

while ($counter <= 3) {
    echo 'Строка ' . $counter . '<br>';
    $counter++;
}
```

Если условие ложно с самого начала, тело не выполнится ни разу. Если условие никогда не станет ложным, цикл не завершится.

> [!WARNING]
>
> Бесконечный цикл на web-сервере не просто зависает: он занимает процесс и потребляет ресурсы, пока не сработает ограничение времени выполнения. Убедитесь, что в теле цикла есть инструкция, которая приближает условие к ложному значению. Чаще всего бесконечный цикл получается из-за забытого `$counter++`.

### Цикл `do...while`

Цикл `do...while` проверяет условие после выполнения тела, поэтому тело выполняется минимум один раз.

_Синтаксис_

```php
do {
    // тело цикла
} while (условие);
```

- Условие проверяется после тела, а не до него.
- Точка с запятой после закрывающей скобки условия обязательна.

_Пример_

```php
<?php

$counter = 10;

do {
    echo 'Выполнилось один раз при $counter = ' . $counter;
} while ($counter < 3);
```

Применяется редко: в основном там, где действие нужно выполнить, а потом решить, повторять ли его.

### Цикл `for`

Цикл `for` собирает три части в одной строке: начальное значение, условие и шаг.

```php
for (инициализация; условие; шаг) {
    // тело цикла
}
```

- `инициализация` - выполняется один раз перед началом цикла.
- `условие` - проверяется перед каждым повторением.
- `шаг` - выполняется после каждого повторения тела.
- Любая из трёх частей может быть пустой, но точки с запятой остаются.

_Пример_

```php
<?php

for ($i = 1; $i <= 3; $i++) {
    echo 'Товар №' . $i . '<br>';
}
```

### Вложенные циклы

Цикл может содержать внутри себя другой цикл. Внешний цикл при этом выполняется медленнее: на каждое его повторение приходится полный проход внутреннего.

```php
<?php

for ($row = 1; $row <= 2; $row++) {
    for ($col = 1; $col <= 3; $col++) {
        echo $row . '-' . $col . ' ';
    }
}
// 1-1 1-2 1-3 2-1 2-2 2-3
```

Счётчики у вложенных циклов обязательно должны быть разными. Если внутренний цикл использует ту же переменную `$i`, что и внешний, он собьёт её значение, и внешний цикл либо завершится раньше времени, либо не завершится вовсе.

Общее количество повторений тела перемножается: два внешних на три внутренних дают шесть. Это стоит помнить, когда во внутреннем цикле окажется запрос к базе данных.

### break и continue

Оператор `break` немедленно прекращает цикл.

_Синтаксис_

```php
break;
break уровни;
```

- Без аргумента прекращает ближайший цикл или конструкцию `switch`.
- `уровни` - целое число, показывающее, из скольких вложенных конструкций выйти.

_Пример_

```php
<?php

for ($i = 1; $i <= 10; $i++) {
    if ($i === 4) {
        break;
    }
    echo $i;   // 123
}
```

Оператор `continue` пропускает остаток текущего повторения и переходит к следующему.

_Синтаксис_

```php
continue;
continue уровни;
```

- Без аргумента переходит к следующему повторению ближайшего цикла.
- `уровни` - целое число, показывающее, для скольких вложенных циклов выполнить переход.

_Пример_

```php
<?php

for ($i = 1; $i <= 5; $i++) {
    if ($i === 3) {
        continue;
    }
    echo $i;   // 1245
}
```

```text
for ($i = 1; $i <= 5; $i++) {
    ...
    continue;  ──> сразу к шагу $i++ и следующей проверке
    ...
    break;     ──> сразу за пределы цикла
    ...
}
<── сюда попадает break
```

## Альтернативный синтаксис

Когда управляющая конструкция окружает HTML, фигурные скобки теряются в разметке:

```php
<?php if ($inStock) { ?>
    <p>В наличии</p>
<?php } else { ?>
    <p>Нет в наличии</p>
<?php } ?>
```

Для таких случаев в PHP есть альтернативная форма записи[^2]: двоеточие вместо открывающей скобки и явное ключевое слово вместо закрывающей.

```php
<?php if ($inStock): ?>
    <p>В наличии</p>
<?php else: ?>
    <p>Нет в наличии</p>
<?php endif; ?>
```

Соответствие простое:

| Обычная запись          | Альтернативная                   |
| ----------------------- | -------------------------------- |
| `if (...) { ... }`      | `if (...): ... endif;`           |
| `for (...) { ... }`     | `for (...): ... endfor;`         |
| `foreach (...) { ... }` | `foreach (...): ... endforeach;` |
| `while (...) { ... }`   | `while (...): ... endwhile;`     |
| `switch (...) { ... }`  | `switch (...): ... endswitch;`   |

Пример с циклом:

```php
<?php for ($i = 1; $i <= 3; $i++): ?>
    <p>Страница <?= $i ?></p>
<?php endfor; ?>
```

Практическое разделение такое:

1. В файлах с логикой используют фигурные скобки,
2. В шаблонах с HTML разметкой - альтернативный синтаксис.

Причина в читаемости: в конце длинного блока `endif` говорит больше, чем одинокая скобка среди десятка закрывающих тегов.

## Практический пример

Соединим изученное в одном файле. Программа выводит карточку товара: считает цену со скидкой, выбирает текст о наличии и рисует шкалу оценки.

```php
<?php

$productName = 'Ноутбук Lenovo IdeaPad 3';
$basePrice = 14999;
$discountPercent = 15;
$stock = 3;
$rating = 4;

$finalPrice = $basePrice - ($basePrice * $discountPercent / 100);

$availability = match (true) {
    $stock === 0 => 'Нет в наличии',
    $stock < 5 => 'Осталось мало: ' . $stock,
    default => 'В наличии',
};

?>
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title><?= $productName ?></title>
</head>
<body>
    <h1><?= $productName ?></h1>

    <?php if ($discountPercent > 0): ?>
        <p>
            <s><?= $basePrice ?> лей</s>
            <strong><?= $finalPrice ?> лей</strong>
            (скидка <?= $discountPercent ?>%)
        </p>
    <?php else: ?>
        <p><strong><?= $basePrice ?> лей</strong></p>
    <?php endif; ?>

    <p><?= $availability ?></p>

    <p>
        Оценка:
        <?php for ($i = 1; $i <= 5; $i++): ?>
            <?= $i <= $rating ? '★' : '☆' ?>
        <?php endfor; ?>
    </p>
</body>
</html>
```

Разберём решения, принятые в этом коде.

1. Конструкция `match (true)` позволяет проверять не равенство одному значению, а несколько разных условий, оставаясь выражением. Это удобная замена цепочке `if`, когда результатом является одно значение.
2. Цикл `for` рисует ровно пять символов оценки, а тернарный оператор внутри выбирает между закрашенной и пустой звездой. Так пять почти одинаковых строк разметки заменяются тремя.
3. Данные по-прежнему записаны прямо в коде. В следующих главах они придут из адресной строки, из формы и из базы данных, а вот вычисления и разметка при этом почти не изменятся.

| `while`                                                           | `while (условие) { }`                                                                               | Повторение с проверкой до тела                                 |
| `do...while`                                                      | `do { } while (условие);`                                                                           | Повторение с проверкой после тела                              |
| `for`                                                             | `for (инициализация; условие; шаг) { }`                                                             | Повторение с известным числом шагов                            |
| `break`                                                           | `break;` или `break уровни;`                                                                        | Прекратить цикл                                                |
| `continue`                                                        | `continue;` или `continue уровни;`                                                                  | Перейти к следующему повторению                                |
| Константы                                                         | `PHP_INT_MAX`, `PHP_INT_MIN`, `PHP_INT_SIZE`, `PHP_FLOAT_MAX`, `PHP_FLOAT_MIN`, `PHP_FLOAT_EPSILON` | Предельные значения числовых типов                             |

## Резюме

1. PHP определяет тип значения автоматически, но типы существуют и влияют на результат операций.
2. Скалярные типы `int`, `float`, `string`, `bool` плюс значение `null` покрывают большинство задач на этом этапе.
3. Дробные числа хранятся приближённо, поэтому сравнивать их на точное равенство нельзя, а деньги удобнее хранить в целых минимальных единицах.
4. Явное преобразование выполняется приведением `(int)`, `(float)`, `(string)`, `(bool)` или функциями `intval()` и подобными, и оно не заменяет проверку данных.
5. При неявном преобразовании в арифметике числовая строка преобразуется молча, строка с числом в начале даёт предупреждение, нечисловая строка вызывает ошибку.
6. В логическом контексте ложными считаются `false`, `0`, `0.0`, `''`, `'0'`, `[]` и `null`, остальное истинно.
7. Оператор `==` сравнивает с приведением типов, `===` сравнивает значение и тип; по умолчанию следует выбирать строгое сравнение.
8. Словесные `and` и `or` имеют более низкий приоритет, чем присваивание, поэтому в коде используются `&&` и `||`.
9. Ветвление реализуется через `if`, `switch` и `match`, причём `match` сравнивает строго и возвращает значение.
10. Циклы `while`, `do...while` и `for` управляются условием, а `break` и `continue` изменяют ход их выполнения.
