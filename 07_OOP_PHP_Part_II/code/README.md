# Код к главе «Объектно-ориентированное программирование в PHP. Часть II»

Все примеры рассчитаны на PHP 8.1 и новее. База данных и Composer не нужны.

**Главное правило:** каждый файл - самостоятельная программа. Внутри него уже объявлены все необходимые классы и интерфейсы. Не нужно подключать другие PHP-файлы или переносить классы между примерами.

## Как запустить

Откройте терминал в папке `code` и выполните одну из команд:

```bash
php demos/01_polymorphism.php
php demos/02_interfaces.php
php demos/03_abstract.php
php demos/04_roles.php
php demos/05_traits.php
php demos/06_composition.php
php demos/07_static.php
php demos/08_magic.php
php demos/09_checkout.php
```

Начните с `01_polymorphism.php`, затем переходите к следующему файлу. Повторяющиеся названия классов встречаются специально: каждый пример решает новую задачу и запускается отдельно.

В файле `09_checkout.php` попробуйте поменять `$deliveryCode` и `$paymentCode`:

- `$deliveryCode`: `courier`, `post`, `pickup` или `express`.
- `$paymentCode`: `cash` или `card`.

## Страница MiniShop в браузере (дополнительно)

`checkout.php` - самостоятельная PHP-страница с HTML-формой. В её начале находятся все нужные определения классов и интерфейсов. Для запуска из папки `code`:

```bash
php -S localhost:8000
```

Откройте `http://localhost:8000/checkout.php`, выберите доставку и оплату и нажмите «Пересчитать».

Все данные учебные: заказ нигде не сохраняется, настоящая оплата не выполняется.
