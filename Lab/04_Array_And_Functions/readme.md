# Лабораторная работа №4. Массивы и функции

## Цель работы

Научиться хранить данные приложения в массиве и обрабатывать их с помощью функций: находить нужные записи, сортировать их и подсчитывать итоги. Начать разработку собственного проекта, который будет дополняться в каждой следующей лабораторной работе.

## Условие

Каждый студент выбирает одну тему и ведёт по ней **семестровый проект** - web-приложение, которое дополняется в каждой следующей лабораторной работе. Проект не переписывается с нуля: новая работа добавляет к нему новый слой.

Код этой работы будет жить долго, и через месяц вы будете читать его заново. _Понятные имена функций и переменных, аккуратное форматирование и отсутствие повторяющихся фрагментов сэкономят вам больше времени, чем кому-либо ещё_.

### Шаг 1. Подготовка проекта

1. Создайте директорию проекта и файл `index.php`.
2. В начале файла включите строгую типизацию:

   ```php
   <?php

   declare(strict_types=1);
   ```

3. Создайте файл `README.md` с описанием проекта: название приложения, одно-два предложения о его назначении и таблица полей записи (название поля, тип PHP, описание, пример значения). Этот файл будет дополняться в каждой следующей лабораторной работе.

### Шаг 2. Создание массива данных

Создайте массив, содержащий данные вашего проекта. Каждая запись представлена в виде ассоциативного массива с одинаковым набором ключей.

_Примечание_: массив обязательно должен содержать:

- от 12 до 15 записей;
- минимум 8 полей в каждой записи;
- поле `id` типа `int`, уникальное для каждой записи;
- строковое поле с названием, по которому будет выполняться поиск;
- строковое поле-категорию с 3-5 различными значениями;
- минимум 2 числовых поля, одно из которых типа `float`;
- минимум 1 поле типа `bool`;
- дату в виде строки в формате `YYYY-MM-DD`;
- поле-список: вложенный массив строк, например теги.

Среди записей должны быть:

- минимум одна запись с пустым полем-списком `[]`;
- минимум одна запись с названием длиннее 40 символов на русском или румынском языке;
- минимум одна категория, в которой ровно одна запись.

**Пример массива**:

```php
$trails = [
    [
        'id' => 1,
        'name' => 'Кольцо вокруг озера Гидигич',
        'region' => 'Страшены',
        'distance' => 12.5,
        'duration' => 240,
        'difficulty' => 2,
        'isCircular' => true,
        'updatedAt' => '2026-04-18',
        'tags' => ['озеро', 'семейный', 'велосипед'],
    ],
    [
        'id' => 2,
        'name' => 'Каприяна: монастырь и лесные тропы Кодр',
        'region' => 'Страшены',
        'distance' => 8.0,
        'duration' => 180,
        'difficulty' => 3,
        'isCircular' => false,
        'updatedAt' => '2025-10-02',
        'tags' => [],
    ],
];
```

> [!TIP]
>
> Даты в формате `YYYY-MM-DD` можно сравнивать как обычные строки: порядок строк совпадает с порядком дат. Поэтому для их сортировки достаточно оператора `<=>`.

### Шаг 3. Параметры отображения

Приложение должно показывать не все данные сразу, а результат, зависящий от параметров: что искать, что отбирать и как сортировать. В следующей работе эти параметры будут приходить из HTML-формы. Сейчас формы нет, поэтому параметры записываются в переменные сразу после данных.

_Пример_

```php
$filters = [
    'region' => '',          // пустая строка: фильтр не применяется
    'minDistance' => null,   // null: нижней границы нет
    'maxDistance' => 15,
    'isCircular' => null,    // null: не важно; true или false: только такие
    'search' => 'озеро',
];

$sortField = 'distance';
$sortDirection = 'desc';
```

_Требования_:

- Массив `$filters` содержит минимум 5 параметров: категорию, нижнюю и верхнюю границу числового поля, логический признак и строку поиска.
- Отсутствие значения параметра обозначается единообразно: пустая строка для строковых параметров и `null` для остальных.
- Переменные `$sortField` и `$sortDirection` задают поле и направление сортировки.

### Шаг 4. Функции форматирования

Создайте функции, которые превращают значения записи в строки для вывода на страницу. Названия функций адаптируйте под свою тему.

1. Создайте функцию форматирования числа с единицей измерения, например `formatDistance(float $km): string`, которая возвращает строку вида `12,5 км`.
   - Используйте функцию `number_format()`.
2. Создайте функцию `shortenText(string $text, int $maxLength): string`, которая сокращает длинный текст и добавляет в конце `...`.
   - Если текст короче `$maxLength`, он возвращается без изменений.
   - Функция должна корректно работать с кириллицей.
3. Создайте функцию `formatTags(array $tags): string`, которая возвращает теги одной строкой через запятую.
   - Перед объединением приведите каждый тег к нижнему регистру с помощью `array_map()` и `mb_strtolower()`.
   - Для пустого массива функция возвращает строку `нет тегов`.
4. Создайте функцию текстовой метки, например `difficultyLabel(int $level): string`, которая возвращает `лёгкий`, `средний` или `сложный`.
   - Для недопустимого значения функция возвращает `неизвестно`.

### Шаг 5. Фильтрация и поиск

Создайте следующие функции. Каждая принимает массив записей и возвращает новый массив, не изменяя исходный.

1. `filterByCategory(array $items, string $category): array` - отбор по категории.
2. `filterByRange(array $items, string $field, int|float|null $min, int|float|null $max): array` - отбор по диапазону числового поля. Имя поля передаётся параметром `$field`, поэтому функция работает для любого числового поля.
3. `filterByFlag(array $items, string $field, ?bool $value): array` - отбор по логическому полю.
4. `searchByName(array $items, string $query): array` - поиск по части названия.
5. `applyFilters(array $items, array $filters): array` - последовательно вызывает предыдущие функции.

_Требования_:

1. Отбор выполняется с помощью `array_filter()` и стрелочных функций.
2. Если параметр фильтра пуст, фильтр не применяется. Например, `filterByCategory()` с пустой строкой возвращает все записи.
3. Поиск не зависит от регистра и пробелов по краям: запрос `'  ОЗЕРО '` находит запись `Кольцо вокруг озера Гидигич`.
4. `applyFilters()` возвращает массив с нумерацией ключей с нуля.

### Шаг 6. Сортировка

Создайте функцию `sortItems(array $items, string $field, string $direction = 'asc'): array`, которая сортирует записи по указанному полю.

_Требования_:

1. Сортировка выполняется с помощью `usort()` и оператора `<=>`.
2. Параметр `$direction` принимает значения `'asc'` (по возрастанию) и `'desc'` (по убыванию).
3. Сортировка возможна по названию, по дате и минимум по двум числовым полям.
4. Допустимые поля перечислены в константе:

   ```php
   const SORT_FIELDS = ['id', 'name', 'distance', 'duration', 'updatedAt'];
   ```

5. Если передано поле, которого нет в `SORT_FIELDS`, записи сортируются по `id`. Для проверки используйте `in_array()` со строгим сравнением.
6. Если передано недопустимое направление, используется `'asc'`.

### Шаг 7. Статистика

Создайте функции, вычисляющие итоговые значения. Статистика считается по отобранным записям, а не по всем данным.

1. `sumField(array $items, string $field): int|float` - сумма числового поля.
   - Используйте `array_column()` и `array_sum()`.
2. `averageField(array $items, string $field): float` - среднее значение числового поля, округлённое до двух знаков.
   - Для округления используйте функцию `round($number, 2)`.
3. `findMax(array $items, string $field): ?array` - запись с наибольшим значением поля.
4. `countByField(array $items, string $field): array` - количество записей в каждой категории в виде `категория => количество`, упорядоченное по убыванию количества.
5. `collectTags(array $items): array` - все теги без повторов, отсортированные по алфавиту.
   - Для удаления повторов используйте функцию `array_unique()`. Она сохраняет ключи, поэтому после неё примените `array_values()`.

_Требования_:

1. Все функции должны корректно работать с пустым массивом: `averageField()` возвращает `0.0`, `findMax()` возвращает `null`, `countByField()` и `collectTags()` возвращают пустой массив.

> [!WARNING]
>
> В PHP 8 деление на ноль завершает скрипт ошибкой `DivisionByZeroError`. Если фильтры не отобрали ни одной записи, среднее значение без проверки на пустой массив остановит всю страницу.

### Шаг 8. Вывод данных

Сформируйте HTML-страницу, которая содержит:

1. Название приложения.
2. Текущие параметры фильтрации и сортировки. Параметр без значения выводится текстом, например `Регион: любой`.
3. Строку вида `Найдено: 4 из 13`.
4. Таблицу с отобранными записями. Каждое поле выводится через соответствующую функцию форматирования. Если записей нет, вместо таблицы выводится сообщение `Ничего не найдено`.
5. Блок статистики: сумму или среднее, запись с наибольшим значением, количество записей по категориям и список всех тегов.

_Требования_:

1. Все вычисления выполняются до начала HTML, результаты сохраняются в переменные. В HTML-части вызываются только функции форматирования и `count()`.
2. Для вывода используйте альтернативный синтаксис `foreach ... endforeach` и `if ... endif`.
3. Функции не выводят данные через `echo` и не используют `global`: результат возвращается через `return`.

## Документация кода

Код должен быть корректно задокументирован, используя стандарт `PHPDoc`. Каждая функция должна быть описана с указанием её входных параметров, возвращаемого значения и назначения.

## Контрольные вопросы

1. Почему функции получают параметры фильтрации через аргументы, а не обращаются к массиву `$filters` напрямую?
2. Почему после `array_filter()` понадобилась функция `array_values()`?
3. Как стрелочная функция внутри `filterByRange()` получает доступ к параметру `$field`? Как пришлось бы записать тот же код с анонимной функцией?
4. Почему для поиска используется `mb_strtolower()`, а не `strtolower()`?
5. Почему функция сортировки возвращает новый массив, а результат её вызова необходимо присвоить переменной?
