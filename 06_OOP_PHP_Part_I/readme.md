## Ретроспектива

В главе 4 товар MiniShop был описан ассоциативным массивом, а каталог - массивом таких массивов. В главе 5 действия над товарами были оформлены функциями: `applyDiscount()`, `filterInStock()`, `sortByPrice()`. Такая организация кода позволила убрать повторы и сделать вычисления многократно используемыми.

Однако данные и правила работы с ними по-прежнему существуют отдельно друг от друга. Массив товара ничего не знает о функциях, которые его обрабатывают, а функции ничего не гарантируют о массиве, который им передан. Эта глава рассматривает механизм, который объединяет данные и правила в одну конструкцию: класс.

Тема объектно-ориентированного программирования разделена на две главы. Эта глава рассматривает устройство отдельного класса и поведение объектов. Следующая глава рассматривает отношения между классами: наследование, интерфейсы и полиморфизм.

## Данные отдельно от правил

Вернёмся к товару в том виде, в котором он описывался в главе 4:

```php
<?php

$product = [
    'name' => 'Ноутбук',
    'price' => 14999,
    'stock' => 3,
];
```

Предположим, что при оформлении заказа остаток на складе уменьшается. Правило простое: нельзя продать больше, чем есть на складе, и остаток не может стать отрицательным. Можно создать функцию, которая будет проверять это правило и обновлять остаток:

```php
<?php

declare(strict_types=1);

function decreaseStock(array $product, int $quantity): array
{
    if ($quantity <= $product['stock']) {
        $product['stock'] -= $quantity;
    }

    return $product;
}
```

Функция соблюдает правило, но ничто не обязывает остальной код ею пользоваться. Любая строка программы может изменить элемент массива напрямую:

```php
<?php

$product = ['name' => 'Ноутбук', 'price' => 14999, 'stock' => 3];

$product['stock'] = -5;   // правило нарушено, PHP не возражает
echo $product['prise'];   // Warning: Undefined array key "prise"
```

Этот фрагмент показывает три недостатка описания сущности массивом.

- _Отсутствие гарантий структуры_. Массив не обязан содержать ключ `'price'`, а значение под ключом `'price'` не обязано быть числом. Опечатка в имени ключа обнаруживается только предупреждением в момент чтения.
- _Отсутствие защиты состояния_. Правило "остаток не бывает отрицательным" записано в функции, но изменить остаток в обход функции может любой фрагмент кода.
- _Разрыв между данными и действиями_. Функции `decreaseStock()`, `applyDiscount()` и подобные им относятся к товару, но связь между ними и массивом существует только в голове разработчика.

Это все недостатки подхода, когда данные и правила работы с ними существуют отдельно друг от друга. Объектно-ориентированное программирование предлагает объединить их в одну конструкцию.

> [!NOTE]
>
> Важно понимать, что данная глава не рассказывает об основах объектно-ориентированного программирования в целом, так как вы это рассматривали на отдельном одноимённом курсе. Здесь внимание сосредоточено на применении ООП в контексте языка PHP.

## Класс и объект

### Понятие класса и объекта

**Класс (class)** - описание структуры и поведения объектов определённого вида: какие данные объект хранит и какие действия над ними можно выполнять.

**Объект (object)**, или **экземпляр класса (instance)**, - конкретное значение, созданное на основе класса и хранящее собственные данные.

Как обычно принято приводить аналогии, класс можно сравнить с чертежом, а объект - с построенным по этому чертежу объектом. Например, класс - чертеж машины, а объект - конкретная машина, построенная по этому чертежу.

### Объявление класса и создание объекта

Класс объявляется ключевым словом `class`, за которым следуют имя класса и тело в фигурных скобках[^1].

_Синтаксис_

```php
class ClassName
{
    // свойства
    // методы
}
```

- `ClassName` - имя класса. По стандарту PSR-1 имена классов записываются в стиле `StudlyCaps`: каждое слово с заглавной буквы, без разделителей, например `Product` или `ShoppingCart`[^2].
- По стандарту PSR-12 открывающая фигурная скобка класса располагается на отдельной строке[^3]

Объект создаётся оператором `new`.

_Синтаксис_

```php
$obj = new ClassName();
```

- `new ClassName()` - Возвращает новый объект указанного класса.
- Каждый вызов `new` создаёт отдельный объект.

К свойствам и методам объекта обращаются через оператор `->`.

_Синтаксис_

```php
$obj->propertyName;
$obj->methodName(arguments);
```

_Пример_

```php
<?php

declare(strict_types=1);

class Product
{
    public string $name = '';
    public int $price = 0;
}

$laptop = new Product();
$laptop->name = 'Ноутбук Lenovo IdeaPad 3';
$laptop->price = 14999;

$mouse = new Product();
$mouse->name = 'Мышь Logitech M185';
$mouse->price = 299;

echo $laptop->name . '<br>';   // Ноутбук Lenovo IdeaPad 3
echo $mouse->price;            // 299
```

Обратите внимание на запись обращения к свойству: знак `$` ставится перед именем переменной, но не перед именем свойства. Запись `$laptop->$name` означает другое: имя свойства берётся из переменной `$name`. Например:

```php
$name = 'price';
echo $laptop->$name; // 14999
```

Функция `var_dump()` из главы 3 выводит объект вместе с именем класса:

```php
var_dump($laptop);
```

```text
object(Product)#1 (2) {
  ["name"]=>
  string(31) "Ноутбук Lenovo IdeaPad 3"
  ["price"]=>
  int(14999)
}
```

- Запись `object(Product)` означает объект класса `Product`.
- Число после знака `#` является идентификатором объекта внутри текущего скрипта.
- Число в скобках показывает количество свойств.

<details>
<summary>Проверьте себя. Что выведет следующий код?</summary>

```php
$a = new Product();
$a->price = 500;

$b = new Product();
echo $b->price;
```

Будет выведено `0`. Переменные `$a` и `$b` содержат два разных объекта, созданных двумя вызовами `new`. Изменение свойства объекта `$a` не затрагивает объект `$b`, у которого цена осталась равной значению по умолчанию.

</details>

## Свойства

### Объявление свойств

**Свойство (property)** - переменная, объявленная внутри класса; каждый объект хранит собственное значение каждого свойства[^4].

_Синтаксис_

```php
class ClassName
{
    modifier type $propertyName;
    modifier type $propertyName = default_value;
}
```

- `modifier` - модификатор видимости. В примерах до раздела "Видимость и инкапсуляция" используется `public`: свойство доступно из любого места программы.
- `type` - объявление типа, рассмотренное в главе 5. Типизированные свойства поддерживаются начиная с PHP 7.4.
- `default_value` - значение, известное до выполнения программы: литерал, константа, массив или выражение из них. Вызов функции здесь недопустим.

Тип свойства проверяется при каждом присваивании. При директиве `declare(strict_types=1)` попытка записать строку в свойство типа `int` завершается ошибкой `TypeError`, как и при передаче неверного аргумента в функцию.

### Неинициализированные свойства

Типизированное свойство без значения по умолчанию после создания объекта находится в неинициализированном состоянии. Это не `null` и не пустая строка: _у свойства нет значения вообще_. Попытка прочитать такое свойство завершается ошибкой[^4]:

```php
<?php

declare(strict_types=1);

class Product
{
    public string $name;
    public int $price = 0;
}

$product = new Product();
echo $product->name;
// Fatal error: Uncaught Error: Typed property Product::$name must not be accessed before initialization
```

Функция `var_dump()` отображает такое свойство как `uninitialized(string)` и не учитывает его в количестве свойств.

### Динамические свойства

Если присвоить значение свойству, которое не объявлено в классе, PHP создаёт так называемое динамическое свойство.

> [!WARNING]
>
> Начиная с PHP 8.2 это действие сопровождается уведомлением `Deprecated`[^4].

```php
$product->prise = 100;
// Deprecated: Creation of dynamic property Product::$prise is deprecated
```

Для сравнения: при работе с массивом опечатка в ключе при записи не вызывала никакого сообщения, а при чтении приводила только к предупреждению. Класс, в котором перечислены все свойства, позволяет обнаружить опечатку сразу.

> [!NOTE]
> Уведомление `Deprecated` означает, что поведение будет запрещено в одной из следующих версий языка. Код с динамическими свойствами не следует писать даже тогда, когда он пока работает.

## Методы класса

**Метод (method)** - функция, объявленная внутри класса[^1].

Метод объявляется так же, как функция в главе 5, но размещается в теле класса и имеет модификатор видимости.

_Синтаксис_

```php
class ClassName
{
    modifier function methodName(type $parameterName, ...): returnType
    {
        // тело метода
    }
}
```

- Имена методов по стандарту PSR-1 записываются в стиле `camelCase`[^2].
- Открывающая фигурная скобка метода, как и у функции, располагается на отдельной строке.

Внутри метода доступна специальная переменная `$this`.

**$this** - переменная, которая внутри метода обозначает объект, для которого метод был вызван[^1].

```php
<?php

declare(strict_types=1);

class Product
{
    public string $name = '';
    public int $price = 0;

    public function priceWithDiscount(int $percent): float
    {
        return $this->price - $this->price * $percent / 100;
    }
}

$laptop = new Product();
$laptop->price = 14999;

$mouse = new Product();
$mouse->price = 299;

echo $laptop->priceWithDiscount(15) . '<br>';   // 12749.15
echo $mouse->priceWithDiscount(15);             // 254.15
```

К свойству класса нельзя обратится без `$this->`, иначе PHP будет искать переменную в локальной области видимости метода, а не в объекте.

_Пример_:

```php
class Product
{
    public int $price = 0;

    public function priceWithDiscount(int $percent): float
    {
        // Ошибка: обращение к свойству без $this->
        return $price - $price * $percent / 100;
    }
}
```

Вызов метода приведёт к ошибке, так как `$price` не определена в локальной области видимости метода.

## Конструктор

### Метод \_\_construct

Создание объекта в предыдущих примерах состоит из нескольких шагов: вызов `new`, затем присваивание каждого свойства. Если одно из присваиваний забыто, объект остаётся заполненным наполовину, и ошибка проявится позднее, при чтении незаполненного свойства.

**Конструктор (constructor)** - метод с именем `__construct`, который PHP автоматически вызывает для каждого нового объекта сразу после его создания[^5].

_Синтаксис_

```php
class ClassName
{
    public function __construct(type $parameterName, ...)
    {
        // инициализация свойств
    }
}

$object = new ClassName($parameterName1, ..., $parameterNameN);
```

- Имя начинается с двух символов подчёркивания.
- Аргументы конструктора передаются в круглых скобках после имени класса в выражении `new ClassName($parameterName1, ..., $parameterNameN)`.
- Для конструктора тип результата не указывается: результатом выражения `new` всегда является созданный объект.

_Пример_

```php
<?php

declare(strict_types=1);

class Product
{
    public string $name;
    public int $price;

    public function __construct(string $name, int $price)
    {
        $this->name = $name;
        $this->price = $price;
    }
}

$laptop = new Product('Ноутбук Lenovo IdeaPad 3', 14999);

echo $laptop->name;    // Ноутбук Lenovo IdeaPad 3
```

Теперь создать товар без названия или цены невозможно: вызов `new Product()` без аргументов остановит скрипт с ошибкой `ArgumentCountError` (недостаточно аргументов), как и вызов функции без обязательного аргумента.

### Продвижение параметров конструктора

В приведённом конструкторе каждое свойство упоминается трижды:

- в объявлении свойства,
- в параметре.
- в присваивании.

Начиная с PHP 8.0 эту запись можно сократить[^5].

**Продвижение параметров конструктора (constructor property promotion)** - сокращённая запись, при которой параметр конструктора с модификатором видимости одновременно объявляет свойство и присваивает ему значение аргумента.

_Синтаксис_

```php
class ClassName
{
    public function __construct(
        modifier type $propertyName1,
        modifier type $propertyName2 = default_value,
    ) {
        // дополнительные действия
    }
}
```

- Параметр с модификатором видимости (`public`, `private` или `protected`) становится свойством с тем же именем и типом.
- Тело конструктора может быть пустым, но фигурные скобки обязательны.
- Продвинутые и обычные параметры можно сочетать в одном конструкторе.

_Пример_

```php
<?php

declare(strict_types=1);

class Product
{
    public function __construct(
        public string $name,
        public int $price,
        public int $stock = 0,
    ) {
    }
}

$laptop = new Product('Ноутбук Lenovo IdeaPad 3', 14999, 3);
$cable = new Product('Кабель HDMI', 149);

echo $cable->stock;   // 0
```

Этот класс эквивалентен классу с тремя объявленными свойствами и тремя присваиваниями в конструкторе.

<details>
<summary>Проверьте себя. Почему в следующем классе вызов <code>echo $p->price</code> завершится ошибкой?</summary>

```php
class Product
{
    public int $price;

    public function __construct(int $price)
    {
        $price = $price;
    }
}

$p = new Product(100);
echo $p->price;
```

Внутри конструктора выполнено присваивание параметра самому себе: `$price` слева и справа означает локальную переменную. Свойство объекта осталось неинициализированным. Правильная запись: `$this->price = $price;` или продвижение параметра `public int $price`.

</details>

## Исключения

### Объект отказывается принимать неверные данные

Конструктор гарантирует, что у товара заполнены все свойства, но не гарантирует, что значения осмысленны. Вызов `new Product('Ноутбук', -100)` создаст товар с отрицательной ценой: тип `int` допускает отрицательные числа.

Проверку логично выполнять в конструкторе: тогда объект с неверными данными не будет создан вовсе. Однако сообщить о неверных данных обычным способом конструктор не может. Он не возвращает значения, поэтому вернуть `false`, как это делали функции в главах 4 и 5, нельзя. Вывести сообщение через `echo` тоже неправильно: программа продолжит работу и получит объект с отрицательной ценой.

Нужен механизм, который прерывает выполнение кода в месте обнаружения ошибки и передаёт сведения о ней тому фрагменту программы, который способен её обработать. Таким механизмом являются исключения.

**Исключение (exception)** - объект, описывающий ошибочную ситуацию, который выбрасывается оператором `throw` или самим PHP, прерывает обычное выполнение программы и передаётся вверх по цепочке вызовов до ближайшего обработчика[^6].

Исключения вы уже встречали. Ошибки `TypeError` в главе 5 и `DivisionByZeroError` в главе 3 являются объектами того же рода, только выбрасывал их сам PHP, а не код программы.

### Генерация исключений

_Синтаксис_

```php
throw new ExceptionClass('Сообщение об ошибке');
```

- `ExceptionClass` — класс исключения, который вы хотите выбросить. Обычно наследуется от базового класса `Exception`.
- Строка в скобках - текст сообщения, передаваемый конструктору класса исключения.
- После `throw` следующие строки не выполняются: управление передаётся ближайшему подходящему блоку `catch`. Если такого блока нет в текущей функции или методе, их выполнение прекращается.

_Пример_

```php
<?php

declare(strict_types=1);

class Product
{
    public function __construct(
        public string $name,
        public int $price,
    ) {
        if ($price < 0) {
            throw new InvalidArgumentException('Цена не может быть отрицательной');
        }
    }
}

$product = new Product('Ноутбук', -100);
echo 'Эта строка не выполнится';
```

_Результат_:

```text
Fatal error: Uncaught InvalidArgumentException: Цена не может быть отрицательной in index.php:12
```

### Перехват исключения

Исключение перехватывается конструкцией `try`/`catch`.

_Синтаксис_

```php
try {
    // код, который может выбросить исключение
} catch (ExceptionClass $e) {
    // обработка исключения
}
```

- `try` - блок, в котором отслеживаются исключения.
- `catch (ExceptionClass $e)` - обработчик. Срабатывает, если в блоке `try` выброшено исключение указанного класса. Переменная `$e` получает объект исключения.
- Метод `$e->getMessage()` возвращает текст сообщения, переданный при создании исключения.
- Если исключения не было, блок `catch` не выполняется.

_Пример_

```php
<?php

declare(strict_types=1);

class Product
{
    public function __construct(
        public string $name,
        public int $price,
    ) {
        if ($price < 0) {
            throw new InvalidArgumentException('Цена не может быть отрицательной');
        }
    }
}

try {
    $product = new Product('Ноутбук', -100);
    echo 'Товар создан';
} catch (InvalidArgumentException $e) {
    echo 'Ошибка: ' . $e->getMessage();
}

echo '<br>Скрипт продолжает работу';
```

_Результат_:

```text
Ошибка: Цена не может быть отрицательной<br>Скрипт продолжает работу
```

Порядок выполнения этого фрагмента:

1. В блоке `try` вызывается конструктор.
2. Конструктор обнаруживает отрицательную цену и выбрасывает исключение. Выполнение конструктора прекращается.
3. Строка `echo 'Товар создан'` пропускается: выполнение блока `try` прерывается в месте выброса.
4. PHP находит обработчик `catch` с подходящим классом и выполняет его.
5. Выполнение продолжается после всей конструкции `try`/`catch`.

### Блок finally

_Синтаксис_

```php
try {
    // код
} catch (ExceptionClass $e) {
    // обработка
} finally {
    // выполняется всегда
}
```

- Блок `finally` выполняется после `try` и `catch` независимо от того, было ли выброшено исключение[^6].
- Блок `try` должен сопровождаться хотя бы одним блоком `catch` или блоком `finally`.

_Пример_

```php
<?php

declare(strict_types=1);

function divide(int $a, int $b): void
{
    try {
        echo $a / $b;
    } catch (DivisionByZeroError $e) {
        echo 'Деление на ноль';
    } finally {
        echo ' | проверка завершена<br>';
    }
}

divide(10, 2);   // 5 | проверка завершена
divide(10, 0);   // Деление на ноль | проверка завершена
```

Строка из блока `finally` выводится в обоих вызовах: и после успешного деления, и после перехвата ошибки. Блок `finally` используется для действий, которые необходимо выполнить в любом случае, например для освобождения ресурсов. Примеры такого рода появятся в главах о работе с файлами и базой данных.

### Исключения и ошибки

Встроенные исключения PHP образуют иерархию. В её вершине находится `Throwable`, общее обозначение всего, что можно выбросить.

Ниже расположены две ветви:

- `Exception`, исключения, которые, как правило, выбрасывает код программы.
- `Error`, ошибки, которые обычно выбрасывает сам PHP[^8].

```text
Throwable
├── Exception
│   └── LogicException
│       └── InvalidArgumentException
└── Error
    ├── TypeError
    │   └── ArgumentCountError
    └── ArithmeticError
        └── DivisionByZeroError
```

Блок `catch` перехватывает исключения указанного класса и всех классов, расположенных ниже него в иерархии.

- Блок `catch (TypeError $e)` перехватит и `ArgumentCountError`.
- Блок `catch (Exception $e)` перехватит `InvalidArgumentException` и все её подклассы.
- Блок `catch (Throwable $e)` перехватит что угодно.

Механизм, на котором основаны эти отношения между классами, называется наследованием и рассматривается в следующей главе.

Поскольку `Error` не входит в ветвь `Exception`, блок `catch (Exception $e)` не перехватывает `TypeError` и другие ошибки PHP[^8].

| Класс                      | Типичный источник | Типичная причина                                                                            |
| -------------------------- | ----------------- | ------------------------------------------------------------------------------------------- |
| `InvalidArgumentException` | Код программы     | Недопустимое значение аргумента                                                             |
| `TypeError`                | PHP               | Аргумент или значение неверного типа                                                        |
| `ArgumentCountError`       | PHP               | Недостаточно аргументов при вызове                                                          |
| `DivisionByZeroError`      | PHP               | Деление на ноль                                                                             |
| `Error`                    | PHP               | Обращение к неинициализированному свойству, к закрытому свойству и другие ошибки выполнения |

## Видимость и инкапсуляция

### Модификаторы видимости

Исключение в конструкторе не позволяет создать товар с отрицательной ценой. Однако если свойство `price` объявлено с модификатором `public`, любой код может изменить его после создания: `$product->price = -100;`.

Проверку в конструкторе в этом случае можно обойти одной строкой. Чтобы правило соблюдалось всегда, нужно ограничить, кто может изменять свойство.

**Член класса (class member)** - свойство, метод или константа, объявленные в классе.

**Модификатор видимости (visibility modifier)** - ключевое слово перед объявлением члена класса, определяющее, из какого кода к нему можно обращаться[^9].

_Синтаксис_

```php
class ClassName {
    modifier type $property;

    modifier const CONSTANT = value;

    modifier function methodName() {
        // тело метода
    }
}
```

- `modifier` - одно из ключевых слов `public`, `private` или `protected`.

| Модификатор | Название   | Где доступен член класса                                           |
| ----------- | ---------- | ------------------------------------------------------------------ |
| `public`    | Открытый   | В любом месте программы                                            |
| `private`   | Закрытый   | Только внутри методов того класса, в котором он объявлен           |
| `protected` | Защищённый | Внутри класса и в классах, связанных с ним наследованием (глава 7) |

Если модификатор не указан, член класса считается `public`[^9]. Стандарт PSR-12 тем не менее требует явно указывать видимость у всех свойств и методов[^3].

Обращение к закрытому члену класса извне завершается ошибкой.

_Пример_

```php
<?php

declare(strict_types=1);

class Product
{
    public function __construct(
        public string $name,
        private int $price,
    ) {
    }
}

$product = new Product('Ноутбук', 14999);
echo $product->price;
// Fatal error: Uncaught Error: Cannot access private property Product::$price
```

### Инкапсуляция

Если свойство закрыто, читать и изменять его можно только через методы класса. Методы проверяют каждое изменение, и правило перестаёт зависеть от аккуратности остального кода.

**Инкапсуляция (encapsulation)** - один из принципов объектно-ориентированного программирования, согласно которому объект скрывает своё внутреннее состояние и позволяет изменять его только через собственные методы, обеспечивающие соблюдение правил.

**Геттер (getter)** - открытый метод, возвращающий значение закрытого свойства. Имя геттера по соглашению начинается с `get`: `getPrice()`, `getStock()`.

_Пример_

```php
<?php

declare(strict_types=1);

class Product
{
    public function __construct(
        public string $name,
        private int $price,
        private int $stock = 0,
    ) {
        if ($price < 0) {
            throw new InvalidArgumentException('Цена не может быть отрицательной');
        }

        if ($stock < 0) {
            throw new InvalidArgumentException('Остаток не может быть отрицательным');
        }
    }

    public function getPrice(): int
    {
        return $this->price;
    }

    public function getStock(): int
    {
        return $this->stock;
    }

    public function decreaseStock(int $quantity): void
    {
        if ($quantity <= 0) {
            throw new InvalidArgumentException('Количество должно быть положительным');
        }

        if ($quantity > $this->stock) {
            throw new InvalidArgumentException('Недостаточно товара на складе');
        }

        $this->stock -= $quantity;
    }
}

$laptop = new Product('Ноутбук', 14999, 3);
$laptop->decreaseStock(2);

echo $laptop->getStock();   // 1
```

Инкапсуляция не означает, что каждому закрытому свойству нужна пара методов `get` и `set`. Метод `setStock(int $stock)`, присваивающий любое значение без проверки, вернул бы ту же проблему, что и открытое свойство.

Методы следует проектировать как действия, имеющие смысл для предметной области: "уменьшить остаток", "применить скидку", а не "присвоить поле".

> [!TIP]
> По умолчанию объявляйте свойства закрытыми и открывайте только то, что действительно нужно внешнему коду. Расширить доступ позднее проще, чем найти и исправить все места, которые изменяли открытое свойство напрямую.

## Неизменяемые свойства

Некоторые данные товара не должны меняться после создания объекта, например, код товара (`id`) и название. Сделать такое свойство `private` можно, но для этого случая в PHP 8.1 появилось более короткое средство[^4].

**Неизменяемое свойство (readonly property)** - свойство, значение которого можно присвоить только один раз, изнутри класса; любая последующая попытка изменения завершается ошибкой.

_Синтаксис_

```php
class ClassName {
    modifier readonly type $property;
}
```

- Модификатор `readonly` применяется только к типизированным свойствам.
- Значение по умолчанию для `readonly` свойства указывать нельзя.
- Значение присваивается один раз, только изнутри класса, обычно в конструкторе.
- Читать свойство можно в соответствии с его видимостью, например из любого места при `public readonly`.

_Пример_

```php
<?php

declare(strict_types=1);

class Product
{
    public function __construct(
        public readonly int $id,
        public readonly string $name,
        private int $price,
    ) {
    }
}

$product = new Product(1, 'Ноутбук', 14999);

echo $product->name;           // Ноутбук
$product->name = 'Планшет';
// Fatal error: Uncaught Error: Cannot modify readonly property Product::$name
```

Запись `public readonly` сочетает удобство открытого свойства для чтения с защитой от изменения. Для кода и названия товара она заменяет пару "закрытое свойство и геттер".

## Константы и статические члены класса

### Константы класса

Свойства, рассмотренные выше, принадлежат объекту: у каждого объекта своё значение. Некоторые значения относятся ко всему классу и одинаковы для всех объектов, например код валюты или максимальная скидка. Для них используются константы класса[^10].

**Константа класса (class constant)** - именованное неизменяемое значение, объявленное внутри класса и общее для всех его объектов.

_Синтаксис_

```php
class ClassName {
   modifier const CONSTANT_NAME = value;
}
```

- Имена констант класса по стандарту PSR-1 записываются заглавными буквами с подчёркиваниями[^2].
- Модификатор видимости необязателен; по умолчанию константа открыта.

Константа принадлежит классу, а не объекту, поэтому к ней обращаются через имя класса и оператор `::`.

**Оператор разрешения области видимости `::` (scope resolution operator)** - оператор обращения к константам, статическим свойствам и статическим методам класса[^11].

_Пример_

```php
<?php

class Product
{
    public const MAX_DISCOUNT = 50;


    public function __construct(
        private int $price,
    ) {
    }

    public function applyDiscount(int $discount): void
    {
        if ($discount > self::MAX_DISCOUNT) {
            $discount = self::MAX_DISCOUNT;
        }
        $this->price -= $this->price * $discount / 100;
    }
}

echo Product::MAX_DISCOUNT; // 50

$product = new Product(14999);

$product->applyDiscount(60); // Попытка применить скидку больше максимальной
echo $product->getPrice(); // 14999 - 50% = 7499.5 (если цена хранится как float)
```

- Вне класса используется имя класса.
- Внутри методов класса используется ключевое слово `self`, обозначающее текущий класс.

### Статические свойства и методы

**Статический член класса (static member)** - свойство или метод, объявленный с ключевым словом `static`, который принадлежит классу, а не объекту, и доступен без создания объекта[^12].

_Синтаксис_

```php
class ClassName {
    modifier static type $propertyName = value;

    modifier static function methodName(): returnType
    {
        // Тело статического метода
    }
}

ClassName::$propertyName; // Доступ к статическому свойству класса без создания объекта
ClassName::methodName(); // Вызов статического метода класса без создания объекта
```

- Обращение выполняется через оператор `::`, а не через `->`[^12].
- Внутри статического метода переменная `$this` недоступна: метод вызывается без объекта.

_Пример_

```php
<?php

declare(strict_types=1);

class Product
{
    private static int $createdCount = 0;

    public function __construct(
        public readonly string $name,
    ) {
        self::$createdCount++;
    }

    public static function getCreatedCount(): int
    {
        return self::$createdCount;
    }
}

new Product('Ноутбук');
new Product('Мышь');

echo Product::getCreatedCount();   // 2
```

Обратите внимание на запись `self::$createdCount`: для статического свойства знак `$` сохраняется после `::`, а для константы, как в `self::MAX_DISCOUNT`, он не используется.

> [!NOTE]
>
> Статическое свойство, как и статическая переменная функции из главы 5, хранит значение только в пределах одного выполнения скрипта. При следующем HTTP-запросе PHP начинает работу заново, и счётчик снова равен нулю. Статические свойства не подходят для хранения данных между запросами.

Статические методы удобны для действий, которым не нужны данные конкретного объекта. Использовать их вместо обычных методов не следует: метод, работающий с данными объекта, должен быть обычным.

## Объект как значение

### Массив копируется, объект нет

В главах 4 и 5 было установлено, что массив при присваивании и при передаче в функцию копируется[^13]. Объекты ведут себя иначе, и это различие является одним из главных источников ошибок при переходе от массивов к объектам.

```php
<?php

declare(strict_types=1);

class Product
{
    public function __construct(
        public string $name,
        public int $price,
    ) {
    }
}

$arrayA = ['name' => 'Ноутбук', 'price' => 14999];
$arrayB = $arrayA;
$arrayB['price'] = 9999;
echo $arrayA['price'] . '<br>';   // 14999, массив $arrayA не изменился

$objectA = new Product('Ноутбук', 14999);
$objectB = $objectA;
$objectB->price = 9999;
echo $objectA->price;    // 9999, изменился и $objectA
```

Переменная с объектом хранит не сам объект, а его идентификатор[^14].

**Идентификатор объекта (object identifier)** - значение, по которому PHP находит объект. Переменная, содержащая объект, на самом деле содержит его идентификатор.

При присваивании `$objectB = $objectA` копируется идентификатор, и обе переменные указывают на один и тот же объект. Номер `#1` в выводе `var_dump()` из раздела "Класс и объект" и есть такой идентификатор.

То же правило действует при передаче объекта в функцию. В главе 5 функция `addToCart()` не могла изменить переданный массив без возврата результата или передачи по ссылке.

```php
<?php

declare(strict_types=1);

class Product
{
    public function __construct(
        public string $name,
        public int $price,
    ) {
    }
}

function markDown(Product $product, int $amount): void
{
    $product->price -= $amount;
}

$laptop = new Product('Ноутбук', 14999);
markDown($laptop, 1000);

echo $laptop->price;   // 13999
```

> [!NOTE]
>
> Такие функции нежелательно использовать для изменения состояния объекта, если это не является их основной задачей. Методы объекта должны изменять его состояние, а внешние функции - нет.

## Копирование и сравнение объектов

### Оператор clone

Если нужна независимая копия объекта, используется оператор `clone`[^15].

_Синтаксис_

```php
$objCopy = clone $obj;
```

- Создаёт новый объект того же класса и копирует в него значения всех свойств.
- _Копирование поверхностное_: если свойство содержит другой объект, копируется идентификатор, и оригинал с копией будут ссылаться на один вложенный объект.

_Пример_

```php
<?php

declare(strict_types=1);

class Product
{
    public function __construct(
        public string $name,
        public int $price,
    ) {
    }
}

$original = new Product('Ноутбук', 14999);
$copy = clone $original;
$copy->price = 9999;

echo $original->price . '<br>';   // 14999
echo $copy->price;                // 9999
```

### Сравнение объектов

Операторы сравнения из главы 3 применимы и к объектам, но их смысл для объектов определяется отдельно[^16].

| Выражение   | Результат `true`, если                                                                    |
| ----------- | ----------------------------------------------------------------------------------------- |
| `$a == $b`  | Объекты одного класса и значения всех свойств попарно равны при сравнении оператором `==` |
| `$a === $b` | Обе переменные указывают на один и тот же объект                                          |

_Пример_

```php
<?php

declare(strict_types=1);

class Product
{
    public function __construct(
        public string $name,
        public int $price,
    ) {
    }
}

$a = new Product('Мышь', 299);
$b = new Product('Мышь', 299);
$c = $a;

var_dump($a == $b);    // bool(true)
var_dump($a === $b);   // bool(false)
var_dump($a === $c);   // bool(true)
```

Объекты `$a` и `$b` созданы двумя вызовами `new`. Они равны по содержимому, но являются разными объектами. Выбор оператора зависит от вопроса: "одинаковы ли данные" или "тот ли это самый объект".

<details>
<summary>Проверьте себя. Какие значения вернут выражения <code>$a == $b</code> и <code>$a === $b</code> после выполнения <code>$b = clone $a</code>?</summary>

`$a == $b` вернёт `true`: копия принадлежит тому же классу и имеет те же значения свойств. `$a === $b` вернёт `false`: оператор `clone` создал новый объект.

</details>

## Класс как тип

В главе 5 в объявлениях типов использовались `int`, `string`, `array` и другие встроенные типы. Имя класса также является типом: параметр с типом `Product` принимает только объекты класса `Product`[^17].

_Синтаксис_

```php
function functionName(ClassName $param): ClassName {}
function anotherFunction(?ClassName $param): ?ClassName {}
```

- Тип `ClassName` требует объект указанного класса. Передача значения другого типа завершается ошибкой `TypeError`.
- Тип `?ClassName` дополнительно допускает `null`, как и `?int` в главе 5.

Типичный случай использования `?ClassName` - функция поиска, которая возвращает найденный объект или `null`, если объект не найден.

_Пример_

```php
<?php

declare(strict_types=1);

class Product
{
    public function __construct(
        public readonly int $id,
        public readonly string $name,
    ) {
    }
}

function findProduct(array $products, int $id): ?Product
{
    foreach ($products as $product) {
        if ($product->id === $id) {
            return $product;
        }
    }

    return null;
}

$products = [
    new Product(1, 'Мышь'),
    new Product(2, 'Клавиатура'),
    new Product(3, 'Монитор'),
];

$found = findProduct($products, 4);
var_dump($found); // null
```

Товара с кодом 4 не существует, поэтому функция `findProduct` возвращает `null`.

Обращение `$found->name` к значению `null` вызывает предупреждение `Attempt to read property "name" on null`, а вызов метода у `null` завершается ошибкой `Error`. Перед каждым обращением к результату поиска пришлось бы проверять его на `null`. Для этого случая в PHP 8.0 появился отдельный оператор[^1].

**Оператор `?->` (nullsafe operator)** - оператор обращения к свойству или методу, который возвращает `null`, если значение слева равно `null`, вместо ошибки.

_Синтаксис_

```php
$obj?->propertyName
$obj?->methodName(arguments)
```

- Если `$obj` равен `null`, выражение возвращает `null`, а метод не вызывается и его аргументы не вычисляются.
- Если `$obj` не равен `null`, выражение работает так же, как обычное обращение через `->`.

_Пример_

```php
var_dump($found?->name);                         // NULL, без предупреждения
var_dump(findProduct($products, 1)?->name);       // string(14) "Ноутбук"

echo $found?->name ?? 'Товар не найден';         // Товар не найден
```

Проверить, является ли значение объектом определённого класса, позволяет оператор `instanceof`[^18].

_Синтаксис_

```php
$obj instanceof ClassName
```

- Возвращает `true`, если значение является объектом указанного класса.
- Если значение не является объектом, возвращает `false` без ошибки.

_Пример_

```php
var_dump($products[0] instanceof Product);   // bool(true)
var_dump($found instanceof Product);        // bool(false), $found равно null
```

## Собираем вместе

Объединим средства главы в фрагменте MiniShop: товары описаны классом `Product`, корзина покупателя описана классом `Cart`. Корзина хранит массив, элементами которого являются объекты товаров, и не позволяет положить в неё больше товара, чем есть на складе.

```php
<?php

declare(strict_types=1);

class Product
{
    public const CURRENCY = 'лей';

    public function __construct(
        public readonly int $id,
        public readonly string $name,
        private int $price,
        private int $stock = 0,
    ) {
        if ($price < 0) {
            throw new InvalidArgumentException('Цена не может быть отрицательной');
        }

        if ($stock < 0) {
            throw new InvalidArgumentException('Остаток не может быть отрицательным');
        }
    }

    public function getPrice(): int
    {
        return $this->price;
    }

    public function getStock(): int
    {
        return $this->stock;
    }
}

class Cart
{
    // Ключ - код товара (свойство id), значение - ['product' => Product, 'quantity' => int]
    private array $items = [];

    public function add(Product $product, int $quantity = 1): void
    {
        if ($quantity <= 0) {
            throw new InvalidArgumentException('Количество должно быть положительным');
        }

        $inCart = $this->items[$product->id]['quantity'] ?? 0;

        if ($inCart + $quantity > $product->getStock()) {
            throw new InvalidArgumentException(
                'Недостаточно товара "' . $product->name . '" на складе'
            );
        }

        $this->items[$product->id] = [
            'product' => $product,
            'quantity' => $inCart + $quantity,
        ];
    }

    public function getItems(): array
    {
        return $this->items;
    }

    public function total(): int
    {
        $total = 0;

        foreach ($this->items as $item) {
            $total += $item['product']->getPrice() * $item['quantity'];
        }

        return $total;
    }
}

function formatPrice(int $price): string
{
    return number_format($price, 0, ',', ' ') . ' ' . Product::CURRENCY;
}

$laptop = new Product(1, 'Ноутбук Lenovo IdeaPad 3', 14999, 3);
$mouse = new Product(2, 'Мышь Logitech M185', 299, 10);

$cart = new Cart();
$error = null;

try {
    $cart->add($laptop);
    $cart->add($mouse, 2);
    $cart->add($laptop, 5);
} catch (InvalidArgumentException $e) {
    $error = $e->getMessage();
}

?>
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>MiniShop - корзина</title>
</head>
<body>
    <h1>Корзина</h1>

    <?php if ($error !== null): ?>
        <p>Ошибка: <?= htmlspecialchars($error) ?></p>
    <?php endif; ?>

    <table>
        <tr>
            <th>Товар</th>
            <th>Цена</th>
            <th>Количество</th>
        </tr>
        <?php foreach ($cart->getItems() as $item): ?>
            <tr>
                <td><?= htmlspecialchars($item['product']->name) ?></td>
                <td><?= formatPrice($item['product']->getPrice()) ?></td>
                <td><?= $item['quantity'] ?></td>
            </tr>
        <?php endforeach; ?>
    </table>

    <p>Итого: <?= formatPrice($cart->total()) ?></p>
</body>
</html>
```

## Типичные ошибки

### Обращение к свойству без $this

```php
public function getPrice(): int
{
    return $price;
    // Warning: Undefined variable $price
    // Fatal error: Uncaught TypeError: Product::getPrice(): Return value must be of type int, null returned
}
```

Внутри метода переменная `$price` является локальной переменной метода, а не свойством объекта. Она не определена, поэтому её значение равно `null`, и PHP сообщает о несоответствии возвращаемого типа. Свойство объекта доступно только как `$this->price`.

### Использование $this в статическом методе

```php
public static function describe(): string
{
    return $this->name;
    // Fatal error: Uncaught Error: Using $this when not in object context
}
```

Статический метод вызывается без объекта, поэтому `$this` в нём не существует.

### Знак $ после оператора ->

```php
echo $product->$name;   // ошибка: имя свойства берётся из переменной $name
echo $product->name;    // правильно
```

### Ожидание копии при присваивании объекта

```php
$discounted = $product;
$discounted->price = 9999;   // изменена цена исходного товара
```

Для получения независимой копии используется `clone`.

### Сравнение объектов оператором == вместо ===

```php
if ($cartItem == $product) {
    // выполнится и для разных объектов с одинаковыми свойствами
}
```

Если требуется проверить, что это тот же самый объект, используется `===`.

### Перехват Exception для ошибок PHP

```php
try {
    $product = new Product('Ноутбук', '14999');
} catch (Exception $e) {
    // не выполнится: при strict_types=1 выбрасывается TypeError,
    // а TypeError не входит в ветвь Exception
}
```

### Открытое свойство в обход правил

```php
class Product
{
    public int $stock = 0;   // любой код может записать -5
}
```

Свойство, изменения которого подчиняются правилам, объявляется `private`, а изменяется методами, проверяющими эти правила.

| ------------------------- | ------------------------------------------------------ | -------------------------------------------- |

| Статический член          | `static`, `ИмяКласса::$свойство`, `ИмяКласса::метод()` | Член класса, не принадлежащий объекту        |

| Класс как тип             | `function f(ИмяКласса $p): ?ИмяКласса`                 | Проверка типа параметра и результата         |

| `instanceof`              | `$значение instanceof ИмяКласса`                       | Проверка принадлежности классу               |

## Резюме

1. Описание сущности ассоциативным массивом не гарантирует структуру данных и не защищает их от изменения в обход правил.
2. Класс описывает данные (свойства) и действия (методы) объектов одного вида; объект создаётся оператором `new` и хранит собственные значения свойств.
3. Внутри метода текущий объект обозначается переменной `$this`, а конструктор `__construct` гарантирует, что объект создаётся полностью заполненным.
4. Исключение прерывает выполнение в месте обнаружения ошибки и передаётся вверх до блока `catch`; неперехваченное исключение завершает скрипт фатальной ошибкой.
5. Ветви `Exception` и `Error` иерархии `Throwable` различны, поэтому `catch (Exception $e)` не перехватывает ошибки PHP вроде `TypeError`.
6. Инкапсуляция достигается закрытыми свойствами и методами, которые проверяют каждое изменение; модификатор `readonly` запрещает изменение свойства после первого присваивания.
7. Константы и статические члены принадлежат классу, а не объекту, и доступны через оператор `::`.
8. Переменная с объектом хранит идентификатор объекта, поэтому присваивание и передача в функцию не создают копию; независимая копия создаётся оператором `clone`.
9. Для объектов `==` сравнивает класс и значения свойств, а `===` проверяет, что это один и тот же объект.
10. Класс используется там, где данные подчиняются правилам; для простых наборов значений и однократных преобразований достаточно массивов и функций.
