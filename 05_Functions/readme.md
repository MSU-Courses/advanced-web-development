## Понятие функции

### Назначение функций

Рассмотрим фрагмент, выводящий цены трёх товаров в формате "14 999 лей":

```php
<?php

echo number_format(14999, 0, ',', ' ') . ' лей<br>';
echo number_format(299, 0, ',', ' ') . ' лей<br>';
echo number_format(3499, 0, ',', ' ') . ' лей<br>';
```

Функция `number_format()` будет рассмотрена в разделе 5.7; здесь важно другое. Правило форматирования записано трижды. Если потребуется изменить валюту или разделитель разрядов, исправлять придётся каждую строку, а в реальном приложении таких строк окажутся десятки в разных файлах.

Функция позволяет записать правило один раз и обращаться к нему по имени.

**Функция** - именованный блок кода, выполняющий определённую задачу, который может принимать входные данные и возвращать результат[^1].

Функции PHP делятся на две группы:

- **Встроенные функции** - функции, входящие в состав языка и его расширений: `count()`, `array_merge()`, `var_dump()` и все остальные, использованные ранее.
- **Пользовательские функции** - функции, которые объявляет разработчик.

С точки зрения вызова эти группы не различаются: встроенная и пользовательская функции вызываются одинаково.

### Объявление функции

_Синтаксис_

```php
function functionName($param1, $param2, ...)
{
    // тело функции
    return значение;
}
```

- `function` - ключевое слово, начинающее объявление.
- `functionName` - имя, по которому функция вызывается. Правила именования совпадают с правилами для переменных, но знак `$` не используется.
- `$param1, ...` - параметры: переменные, получающие значения при вызове. Список может быть пустым, круглые скобки при этом обязательны.
- Тело функции - инструкции, выполняемые при каждом вызове.
- `return` - оператор, завершающий выполнение функции и возвращающий значение (раздел 5.2).

_Пример_

```php
<?php

function formatPrice($price)
{
    return number_format($price, 0, ',', ' ') . ' лей';
}
```

Объявление функции само по себе ничего не выполняет. Оно лишь сообщает PHP, что под именем `formatPrice` существует такой блок кода.

> [!NOTE]
> Стандарт оформления кода PSR-12 предписывает размещать открывающую фигурную скобку функции на отдельной строке, в отличие от управляющих конструкций `if`, `for` и `foreach`, у которых скобка остаётся на строке с условием[^2]. Этот стиль используется во всех примерах курса.

### Вызов функции

_Синтаксис_

```php
functionName(arg1, arg2, ...)
```

- `arg1, ...` - значения, передаваемые в функцию. Первый аргумент присваивается первому параметру, второй - второму и так далее.
- Вызов является выражением: его значением становится результат, возвращённый функцией.

_Пример_

```php
<?php

function formatPrice($price)
{
    return number_format($price, 0, ',', ' ') . ' лей';
}

echo formatPrice(14999) . '<br>';   // 14 999 лей
echo formatPrice(299) . '<br>';     // 299 лей
echo formatPrice(3499) . '<br>';    // 3 499 лей
```

Термины "параметр" и "аргумент" обозначают разные вещи и не являются синонимами.

**Параметр** - переменная, объявленная в заголовке функции (`$price`).

**Аргумент** - конкретное значение, передаваемое при вызове (`14999`).

```text
Объявление:   function formatPrice($price)       <- параметр
                         ▲
                         │ значение 14999 присваивается параметру $price
                         │
Вызов:        formatPrice(14999)                  <- аргумент
                         │
                         ▼
Результат:    '14 999 лей'                        <- возвращаемое значение
```

### Правила объявления

Три правила, связанные с объявлением функций, часто становятся неожиданными для тех, кто знаком с другими языками.

- _Первое_: имена функций нечувствительны к регистру. Вызовы `formatPrice()`, `FORMATPRICE()` и `formatprice()` обращаются к одной и той же функции. Имена переменных, как было показано в главе 2, к регистру чувствительны. Несмотря на это правило, функцию следует вызывать в том написании, в котором она объявлена.

- _Второе_: функция, объявленная на верхнем уровне файла, доступна во всём файле, в том числе до места объявления. PHP обрабатывает объявления функций до начала выполнения кода.

  ```php
  <?php

  echo formatPrice(299);   // работает, хотя функция объявлена ниже

  function formatPrice($price)
  {
      return number_format($price, 0, ',', ' ') . ' лей';
  }
  ```

- _Третье_: две функции не могут иметь одинаковое имя. Повторное объявление функции с существующим именем, в том числе с именем встроенной функции, приводит к ошибке `Cannot redeclare`.

### Одна функция - одна задача

Функция должна решать одну задачу, которую можно описать коротким предложением без союза "_и_". Этот принцип известен как принцип единственной ответственности (_Single Responsibility Principle_).

Функция, нарушающая этот принцип:

```php
<?php

function printCartTotal($prices)
{
    $total = array_sum($prices);
    echo 'Итого: ' . $total . ' лей';
}
```

Она выполняет две задачи: вычисляет сумму и выводит её. Результат вычисления нельзя использовать иначе, например сравнить с порогом бесплатной доставки или вывести в другом формате.

Разделение на две функции устраняет проблему:

```php
<?php

function cartTotal($prices)
{
    return array_sum($prices);
}

function formatPrice($price)
{
    return number_format($price, 0, ',', ' ') . ' лей';
}

$prices = [14999, 299];
$total = cartTotal($prices);

echo 'Итого: ' . formatPrice($total);

if ($total >= 1000) {
    echo '<br>Доставка бесплатна';
}
```

## Возвращаемое значение

### Оператор return

_Синтаксис_

```php
return expression;
return;
```

- `expression` - значение, которое становится результатом вызова функции.
- Выполнение функции прекращается немедленно; инструкции после `return` не выполняются.
- Запись `return;` без выражения завершает функцию и возвращает `null`.
- Если в функции нет оператора `return`, она также возвращает `null`.

Функция может содержать несколько операторов `return`, но при каждом вызове выполняется только один из них:

```php
<?php

function stockLabel($stock)
{
    if ($stock === 0) {
        return 'Нет в наличии';
    }

    if ($stock < 5) {
        return 'Осталось мало';
    }

    return 'В наличии';
}

echo stockLabel(0);    // Нет в наличии
echo stockLabel(3);    // Осталось мало
echo stockLabel(12);   // В наличии
```

Этот пример применяет к функции приём раннего выхода из главы 3: каждое условие завершает функцию, как только результат определён, и вложенность не возникает.

### Возврат значения и вывод

Функция может передать результат двумя способами: вернуть его оператором `return` или вывести через `echo`. Эти способы не равнозначны.

```php
<?php

function discountEcho($price)
{
    echo $price * 0.9;
}

function discountReturn($price)
{
    return $price * 0.9;
}

$a = discountEcho(1000);     // выводит 900, $a равно null
$b = discountReturn(1000);   // ничего не выводит, $b равно 900
```

Результат функции `discountEcho()` сразу попадает в ответ сервера, и программа не может его сохранить, сравнить или обработать. Результат `discountReturn()` является значением, с которым вызывающий код волен поступить как угодно, в том числе вывести.

> [!TIP]
> Функции, вычисляющие данные, должны возвращать результат, а не выводить его. Вывод выполняется в одном месте, в шаблоне страницы. Такое разделение впоследствии позволит использовать одни и те же функции и для HTML-страницы, и для ответа в формате JSON.

## Параметры функции

### Объявление параметров

Параметры функции указываются в круглых скобках после имени функции. Они позволяют передавать значения внутрь функции.

_Синтаксис_

```php
function functionName($arg1, $arg2) {
    // тело функции
}
```

Например, функция может принимать несколько параметров и использовать их внутри своего тела:

```php
function sum($a, $b) {
    return $a + $b;
}

echo sum(3, 4); // 7
```

### Значения по умолчанию

Параметру можно назначить значение, которое используется, если соответствующий аргумент при вызове не передан. Такой параметр называется необязательным.

_Синтаксис_

```php
function functionName($required, $optional = value)
{
    // тело функции
}
```

- `value` - константное выражение: литерал, константа или массив из литералов. Вызов функции или переменная в качестве значения по умолчанию недопустимы.
- Необязательные параметры располагаются после обязательных.

```php
<?php

function formatPrice($price, $currency = 'лей')
{
    return number_format($price, 0, ',', ' ') . ' ' . $currency;
}

echo formatPrice(14999);          // 14 999 лей
echo formatPrice(14999, 'EUR');   // 14 999 EUR
```

Если необязательный параметр объявлен перед обязательным, PHP 8 выдаёт уведомление `Deprecated` и считает такой параметр обязательным, так как пропустить его при позиционной передаче аргументов невозможно.

### Именованные аргументы

Начиная с PHP 8 аргумент можно передать не по позиции, а по имени параметра[^3].

_Синтаксис_

```php
functionName(paramName: value, ...)
```

- `paramName` - - имя параметра без знака `$`.
- Порядок именованных аргументов может не совпадать с порядком параметров.
- Позиционные аргументы, если они используются, записываются перед именованными.

```php
<?php

function formatPrice($price, $currency = 'лей', $decimals = 0)
{
    return number_format($price, $decimals, ',', ' ') . ' ' . $currency;
}

echo formatPrice(149.9, decimals: 2);    // 149,90 лей
```

Такое часто используется, когда функция имеет много параметров, и нужно передать только некоторые из них, не заботясь о порядке.

### Переменное число аргументов

Функция может принимать произвольное количество аргументов. Для этого перед последним параметром записывается оператор `...`.

_Синтаксис_

```php
function functionName($param, ...$others)
{
    // $others - массив переданных аргументов
}
```

- Все аргументы, начиная с соответствующей позиции, собираются в индексированный массив.
- Такой параметр может быть только последним.
- Если аргументы не переданы, параметр содержит пустой массив.

Тот же оператор `...` в вызове функции выполняет обратное действие: распаковывает массив в отдельные аргументы.

_Синтаксис_

```php
functionName(...$array)
```

_Пример_

```php
<?php

function cartTotal(...$prices)
{
    return array_sum($prices);
}

echo cartTotal(14999, 299, 1899);   // 17197
echo cartTotal();                   // 0

$prices = [3499, 299];
echo cartTotal(...$prices);         // 3798
```

### Передача по значению и по ссылке

По умолчанию аргументы передаются **по значению**: параметр получает копию значения, и изменения параметра внутри функции не затрагивают переменную вызывающего кода. Это правило распространяется и на массивы.

```php
<?php

function addToCart($cart, $item)
{
    $cart[] = $item;
}

$cart = ['Ноутбук'];
addToCart($cart, 'Мышь');

print_r($cart);   // Array ( [0] => Ноутбук )
```

Функция добавила элемент в свою копию массива, а массив `$cart` вызывающего кода остался прежним. Правильное решение - вернуть изменённый массив и присвоить результат:

```php
<?php

function addToCart($cart, $item)
{
    $cart[] = $item;
    return $cart;
}

$cart = ['Ноутбук'];
$cart = addToCart($cart, 'Мышь');

print_r($cart);   // Array ( [0] => Ноутбук [1] => Мышь )
```

> [!NOTE]
>
> Копирование массива при передаче в функцию не означает немедленного копирования всех элементов. PHP создаёт фактическую копию только в момент первого изменения массива внутри функции. Поэтому передача большого массива в функцию, которая его только читает, не приводит к лишним затратам памяти.

Второй способ - **передача по ссылке**. Параметр, перед именем которого указан знак `&`, становится вторым именем переменной вызывающего кода, и изменения параметра изменяют эту переменную.

_Синтаксис_

```php
function functionName(&$param)
{
    // изменение $param изменяет переменную вызывающего кода
}
```

- При вызове в качестве аргумента допускается только переменная или элемент массива, но не литерал и не выражение.

_Пример_

```php
<?php

function addToCart(&$cart, $item)
{
    $cart[] = $item;
}

$cart = ['Ноутбук'];
addToCart($cart, 'Мышь');

print_r($cart);   // Array ( [0] => Ноутбук [1] => Мышь )
```

Именно так устроены функции `sort()`, `array_push()` и `array_pop()` из главы 4: в их сигнатурах первый параметр записан как `&$array`.

> [!TIP]
>
> Передача по ссылке делает поведение функции менее очевидным: из вызова `addToCart($cart, 'Мышь')` не видно, что переменная `$cart` будет изменена. Поэтому в собственных функциях предпочтение отдаётся возврату результата, а ссылки используются тогда, когда без них решение становится заметно сложнее.

## Объявление типов

### Назначение объявлений типов

В главе 3 отмечалось, что типы можно указывать явно, но для этого нужны функции. Функция `formatPrice($price)` из предыдущих разделов ничего не сообщает о том, что параметр `$price` должен быть числом. Передача строки или массива обнаружится только в момент ошибки внутри функции, причём сообщение об ошибке будет указывать на строку внутри функции, а не на неверный вызов.

**Объявление типа (type declaration)** - указание допустимого типа параметра или возвращаемого значения в заголовке функции, проверяемое PHP при каждом вызове[^4].

_Синтаксис_

```php
function functionName(type $param, ...): return_type
{
    // тело функции
}
```

- `type` - тип параметра. Указывается перед именем параметра.
- `return_type` - тип возвращаемого значения. Указывается после двоеточия за списком параметров.

_Пример_

```php
<?php

function formatPrice(int $price, string $currency = 'лей'): string
{
    return number_format($price, 0, ',', ' ') . ' ' . $currency;
}
```

Заголовок функции теперь полностью описывает её контракт: она принимает целое число и строку и возвращает строку.

### Допустимые типы

| Запись                           | Значение                                            |
| -------------------------------- | --------------------------------------------------- |
| `int`, `float`, `string`, `bool` | Скалярные типы из главы 3                           |
| `array`                          | Массив                                              |
| `?int`                           | Указанный тип или `null`                            |
| `int\|float`                     | Любой из перечисленных типов                        |
| `mixed`                          | Значение любого типа                                |
| `void`                           | Только для результата: функция ничего не возвращает |

Запись `?тип` применяется для параметров, которые могут отсутствовать по смыслу:

```php
<?php

function discountLabel(?int $percent): string
{
    if ($percent === null) {
        return 'Без скидки';
    }

    return 'Скидка ' . $percent . '%';
}

echo discountLabel(null);   // Без скидки
echo discountLabel(15);     // Скидка 15%
```

Тип `void` указывает, что функция выполняет действие, но значения не возвращает. В такой функции допустим только оператор `return;` без выражения.

### Режим проверки типов

По умолчанию PHP работает в режиме приведения типов: если аргумент имеет другой тип, но может быть преобразован по правилам главы 3 без потери смысла, преобразование выполняется автоматически.

```php
<?php

function sum(int $a, int $b): int
{
    return $a + $b;
}

var_dump(sum('5', 3));   // int(8), строка '5' приведена к int
var_dump(sum(2.0, 3));   // int(5), float без дробной части приведён к int
sum('abc', 3);           // TypeError: Argument #1 ($a) must be of type int, string given
```

Директива `declare(strict_types=1)` включает строгий режим, в котором аргумент должен иметь в точности объявленный тип. Единственное исключение: целое число допускается там, где объявлен `float`.

_Синтаксис_

```php
<?php

declare(strict_types=1);
```

- Директива записывается первой инструкцией файла, сразу после открывающего тега.
- Действует только на вызовы функций, выполняемые в этом файле.

_Пример_

```php
<?php

declare(strict_types=1);

function sum(int $a, int $b): int
{
    return $a + $b;
}

var_dump(sum(5, 3));     // int(8)
sum('5', 3);             // TypeError: Argument #1 ($a) must be of type int, string given
```

| Вызов `sum(...)` | Режим по умолчанию             | `strict_types=1` |
| ---------------- | ------------------------------ | ---------------- |
| `sum(5, 3)`      | `8`                            | `8`              |
| `sum('5', 3)`    | `8`                            | `TypeError`      |
| `sum(2.0, 3)`    | `5`                            | `TypeError`      |
| `sum(2.5, 3)`    | `5` и уведомление `Deprecated` | `TypeError`      |
| `sum('abc', 3)`  | `TypeError`                    | `TypeError`      |

Строгий режим обнаруживает ошибку в месте неверного вызова, а не при последующем использовании неверного значения. С этой главы все примеры, содержащие функции, используют объявления типов и директиву `declare(strict_types=1)`.

> [!IMPORTANT]
>
> Строгий режим не отменяет необходимость приводить внешние данные к нужному типу. Значения, поступающие из формы или адресной строки, являются строками, и перед передачей в функцию с параметром `int` их необходимо проверить и явно преобразовать, как было показано в главе 3.

## Область видимости переменных

### Локальная область видимости

**Область видимости (scope)** - часть программы, в которой переменная доступна по своему имени[^5].

Каждый вызов функции создаёт собственную локальную область видимости. Переменные, объявленные внутри функции, включая параметры, существуют только во время её выполнения и недоступны снаружи. Переменные, объявленные вне функций, недоступны внутри функций.

```php
<?php

$vatRate = 0.2;

function priceWithVat(int $price): float
{
    return $price + $price * $vatRate;
}

echo priceWithVat(1000);
// Warning: Undefined variable $vatRate
// 1000
```

Переменная `$vatRate` внутри функции не определена: PHP выдаёт предупреждение, подставляет `null`, и функция возвращает неверный результат.

В этом состоит отличие PHP от JavaScript, где функция автоматически видит переменные внешней области. В PHP функция получает данные только через параметры.

Правильное решение - передать значение параметром:

```php
<?php

declare(strict_types=1);

function priceWithVat(int $price, float $vatRate): float
{
    return $price + $price * $vatRate;
}

echo priceWithVat(1000, 0.2);   // 1200
```

Если значение неизменно для всего приложения, его объявляют константой: константы, в отличие от переменных, доступны внутри функций.

```php
<?php

declare(strict_types=1);

const VAT_RATE = 0.2;

function priceWithVat(int $price): float
{
    return $price + $price * VAT_RATE;
}

echo priceWithVat(1000);   // 1200
```

### Ключевое слово global

PHP позволяет обратиться к глобальной переменной из функции с помощью ключевого слова `global`.

_Синтаксис_

```php
global $переменная;
```

- Связывает локальное имя с одноимённой глобальной переменной.

Такой код работает, но функция перестаёт быть самостоятельной: её результат зависит от переменной, которая может быть изменена в любом месте программы, и из заголовка функции эта зависимость не видна.

### Статические переменные

Локальная переменная уничтожается после завершения вызова. Если значение должно сохраняться между вызовами одной функции, переменная объявляется статической.

_Синтаксис_

```php
static $var = initial_value;
```

- Инициализация выполняется один раз, при первом вызове функции.
- При последующих вызовах переменная сохраняет значение, полученное в предыдущем вызове.
- Переменная остаётся локальной и недоступна вне функции.

_Пример_

```php
<?php

declare(strict_types=1);

function nextRowNumber(): int
{
    static $counter = 0;
    $counter++;

    return $counter;
}

echo nextRowNumber();   // 1
echo nextRowNumber();   // 2
echo nextRowNumber();   // 3
```

> [!NOTE]
> Статическая переменная сохраняет значение только в пределах одного выполнения скрипта. Как было показано в главе 1, PHP обрабатывает каждый HTTP-запрос заново, поэтому при следующем запросе счётчик снова начнётся с единицы.

## Функции как значения

### Понятие callable

В PHP функцию можно сохранить в переменной, передать в другую функцию в качестве аргумента и вызвать позднее.

**Callable** - значение, которое может быть вызвано как функция.

**Callback-функция (функция обратного вызова)** - функция, передаваемая в другую функцию для последующего вызова.

Значением типа `callable` может быть:

- строка с именем существующей функции, например `'trim'` или `'strtoupper'`;
- анонимная функция;
- стрелочная функция.

Строка с именем функции вызывается так же, как сама функция:

```php
<?php

$transform = 'strtoupper';
echo $transform('minishop');   // MINISHOP
```

Этот механизм полезен прежде всего в сочетании со встроенными функциями обработки массивов, которые принимают callback-функцию (раздел 5.6.4).

### Анонимные функции

**Анонимная функция** - функция без имени, создаваемая как значение выражения[^6].

_Синтаксис_

```php
function ($param1, ...) use ($globalVar1, ...): result_type {
    // тело функции
};
```

- Записывается как выражение, поэтому после закрывающей скобки при присваивании ставится точка с запятой.
- `use ($globalVar1, ...)` - необязательный список переменных внешней области, доступных внутри функции. Значения копируются в момент создания функции.
- Для изменения внешней переменной её указывают по ссылке: `use (&$globalVar1, ...)`.

_Пример_

```php
<?php

declare(strict_types=1);

$discountPercent = 10;

$applyDiscount = function (int $price) use ($discountPercent): float {
    return $price - $price * $discountPercent / 100;
};

echo $applyDiscount(2000);   // 1800
```

Важно, что `use` захватывает значение в момент создания функции:

```php
<?php

declare(strict_types=1);

$discountPercent = 10;

$applyDiscount = function (int $price) use ($discountPercent): float {
    return $price - $price * $discountPercent / 100;
};

$discountPercent = 50;

echo $applyDiscount(200);   // 180, используется значение 10
```

Анонимная функция, захватывающая переменные внешней области, называется **замыканием (closure)**.

### Стрелочные функции

Для коротких функций, состоящих из одного выражения, в PHP 7.4 появилась сокращённая запись[^7].

_Синтаксис_

```php
fn ($param1, ...): result_type => expression;
```

- Тело состоит из одного выражения, значение которого возвращается автоматически. Оператор `return` не пишется.
- Переменные внешней области захватываются автоматически, по значению, без списка `use`.
- Изменить внешнюю переменную из стрелочной функции невозможно.

_Пример_

```php
<?php

declare(strict_types=1);

$discountPercent = 10;

$applyDiscount = fn (int $price): float => $price - $price * $discountPercent / 100;

echo $applyDiscount(2000);   // 1800
```

| Свойство                     | Анонимная функция                  | Стрелочная функция      |
| ---------------------------- | ---------------------------------- | ----------------------- |
| Запись                       | `function (...) use (...) { ... }` | `fn (...) => выражение` |
| Тело                         | Любое количество инструкций        | Одно выражение          |
| Захват внешних переменных    | Явно, через `use`                  | Автоматически           |
| Изменение внешней переменной | Возможно через `use (&$x)`         | Невозможно              |

### Обработка массивов с помощью callback-функций

Три встроенные функции покрывают большинство задач обработки массивов: преобразование каждого элемента, отбор элементов по условию и сортировку по произвольному правилу.

Функция `array_map()` применяет callback-функцию к каждому элементу и возвращает массив результатов.

_Синтаксис_

```php
array_map(?callable $callback, array $array, array ...$arrays): array
```

- `$callback` - функция, получающая значение элемента и возвращающая новое значение.
- `$array` - исходный массив; не изменяется.
- Возвращает новый массив той же длины. Если передан один массив, ключи сохраняются.

Функция `array_filter()` оставляет только те элементы, для которых callback-функция вернула истинное значение.

_Синтаксис_

```php
array_filter(array $array, ?callable $callback = null, int $mode = 0): array
```

- `$array` - исходный массив; не изменяется.
- `$callback` - функция, получающая значение элемента и возвращающая `true` для элементов, которые нужно оставить. Если не указана, удаляются все элементы, ложные по правилам главы 3.
- `$mode` - режим передачи данных в callback-функцию. Значение по умолчанию передаёт только значение элемента.
- Возвращает новый массив. Ключи сохраняются, поэтому в нумерации возможны пропуски.

_Пример_

```php
<?php

declare(strict_types=1);

$products = [
    ['name' => 'Ноутбук', 'price' => 14999, 'stock' => 3],
    ['name' => 'Мышь', 'price' => 299, 'stock' => 0],
    ['name' => 'Монитор', 'price' => 3499, 'stock' => 12],
];

$names = array_map(fn (array $p): string => $p['name'], $products);
// ['Ноутбук', 'Мышь', 'Монитор']

$available = array_filter($products, fn (array $p): bool => $p['stock'] > 0);
// элементы с ключами 0 и 2


$cleanTags = array_map('trim', [' php ', 'web ', ' sql']);
// ['php', 'web', 'sql']
```

Результат `array_filter()` сохраняет исходные ключи. Если отфильтрованный массив далее обрабатывается циклом `for` или должен иметь непрерывную нумерацию, к нему применяется `array_values()`:

```php
<?php

declare(strict_types=1);

$numbers = [1, 2, 3, 4, 5, 6];

$even = array_filter($numbers, fn (int $n): bool => $n % 2 === 0);
print_r($even);                  // Array ( [1] => 2 [3] => 4 [5] => 6 )

print_r(array_values($even));    // Array ( [0] => 2 [1] => 4 [2] => 6 )
```

<details>
<summary>Проверьте себя. Почему следующий код не сортирует массив <code>$products</code>, объявленный вне функции?</summary>

```php
function sortByPrice(array $products): void
{
    usort($products, fn (array $a, array $b): int => $a['price'] <=> $b['price']);
}

sortByPrice($products);
```

Массив передан в функцию по значению. Функция `usort()` отсортировала локальную копию, которая уничтожилась после завершения вызова. Функция должна вернуть отсортированный массив (тип результата `array`), а вызывающий код должен присвоить результат: `$products = sortByPrice($products);`.

</details>

## Встроенные функции для работы со строками

### Байты и символы

Прежде чем использовать строковые функции, необходимо знать одно правило, определяющее выбор между ними. Строка PHP является последовательностью байтов, а не символов. В кодировке UTF-8 латинская буква занимает один байт, а буква кириллицы два байта.

Функция `strlen()` возвращает длину строки в байтах:

```php
<?php

echo strlen('Hello');    // 5
echo strlen('Привет');   // 12
```

Для текста только из латинских букв количество байтов совпадает с количеством символов, и ошибка незаметна. Для кириллицы результат оказывается вдвое больше ожидаемого. Функции, работающие с позициями внутри строки, в таком случае могут разрезать символ пополам:

```php
<?php

echo substr('Ноутбук', 0, 3);   // "Н" и половина следующей буквы, выводится некорректный символ
```

Для корректной работы с текстом в UTF-8 предназначено расширение mbstring (multibyte string), функции которого имеют префикс `mb_` и считают символы, а не байты[^8].

| Задача          | Функция для байтов | Функция для символов UTF-8 |
| --------------- | ------------------ | -------------------------- |
| Длина строки    | `strlen()`         | `mb_strlen()`              |
| Часть строки    | `substr()`         | `mb_substr()`              |
| Нижний регистр  | `strtolower()`     | `mb_strtolower()`          |
| Верхний регистр | `strtoupper()`     | `mb_strtoupper()`          |

> [!IMPORTANT]
>
> Если строка может содержать символы за пределами латинского алфавита, а в приложении на русском или румынском языке это почти любая строка, следует использовать функции с префиксом `mb_`. Функции `strtolower()` и `strtoupper()` оставляют кириллицу без изменений.

> [!NOTE]
>
> Если при вызове функции `mb_strlen()` возникает ошибка `Call to undefined function`, расширение mbstring не подключено. Его необходимо включить в файле `php.ini` строкой `extension=mbstring` и перезапустить web-сервер, как было описано в главе 2.

Функции, не зависящие от позиций символов, например `trim()`, `str_replace()` и `str_contains()`, корректно работают с UTF-8 без префикса `mb_`.

### Длина и часть строки

_Синтаксис_

```php
mb_strlen(string $string, ?string $encoding = null): int
```

- `$string` - исходная строка.
- `$encoding` - кодировка. Если не указана, используется кодировка по умолчанию, обычно UTF-8.
- Возвращает количество символов.

_Синтаксис_

```php
mb_substr(string $string, int $start, ?int $length = null, ?string $encoding = null): string
```

- `$string` - исходная строка.
- `$start` - позиция первого символа, начиная с нуля. Отрицательное значение отсчитывается от конца строки.
- `$length` - количество символов. Если не указано, извлекается остаток строки.
- Возвращает часть строки.

_Пример_. Сокращение описания товара

```php
<?php

$description = 'Лёгкий ноутбук для учёбы и работы';

if (mb_strlen($description) > 20) {
    $description = mb_substr($description, 0, 20) . '...';
}

echo $description;   // Лёгкий ноутбук для у...
```

### Удаление пробелов и изменение регистра

_Синтаксис_

```php
trim(string $string, string $characters = " \n\r\t\v\x00"): string
```

- `$string` - исходная строка.
- `$characters` - удаляемые символы. По умолчанию удаляются пробелы, переводы строки, табуляции и нулевой байт.
- Возвращает строку без указанных символов в начале и в конце. Символы внутри строки не удаляются.

Для удаления символов только в начале или только в конце строки существуют функции `ltrim()` и `rtrim()` с той же сигнатурой.

_Синтаксис_

```php
mb_strtolower(string $string, ?string $encoding = null): string
mb_strtoupper(string $string, ?string $encoding = null): string
```

- `$string` - исходная строка.
- Возвращают строку, приведённую к нижнему или верхнему регистру.

_Пример_. Нормализация введённого email

```php
<?php

$input = '  Ana.Popescu@Example.COM ';

$email = mb_strtolower(trim($input));

echo $email;   // ana.popescu@example.com
```

Нормализация необходима для корректного сравнения: адреса `Ana@Example.com` и ` ana@example.com` с точки зрения пользователя одинаковы, а для оператора `===` различны.

### Поиск подстроки

В PHP 8 появились три функции, отвечающие на вопрос о наличии подстроки логическим значением.

_Синтаксис_

```php
str_contains(string $haystack, string $needle): bool
str_starts_with(string $haystack, string $needle): bool
str_ends_with(string $haystack, string $needle): bool
```

- `$haystack` - строка, в которой выполняется поиск.
- `$needle` - искомая подстрока. Сравнение чувствительно к регистру.
- Возвращают `true`, если подстрока содержится в строке, находится в её начале или в её конце соответственно.

_Пример_

```php
<?php

$fileName = 'laptop-lenovo.jpg';

var_dump(str_ends_with($fileName, '.jpg'));        // bool(true)
var_dump(str_contains($fileName, 'lenovo'));       // bool(true)
var_dump(str_starts_with($fileName, 'monitor'));   // bool(false)
```

> [!NOTE]
> В коде, написанном до PHP 8, для той же задачи используется функция `strpos()`, возвращающая позицию подстроки или `false`. Поскольку позиция может быть равна `0`, её результат необходимо сравнивать строго: `strpos($s, $x) !== false`. Это та же ловушка, что и у функции `array_search()` из главы 4 (раздел 4.6.1).

### Замена подстроки

_Синтаксис_

```php
str_replace(array|string $search, array|string $replace, string|array $subject, int &$count = null): string|array
```

- `$search` - искомая подстрока или массив подстрок.
- `$replace` - заменяющая строка или массив строк. Если оба параметра являются массивами, замена выполняется попарно.
- `$subject` - строка, в которой выполняется замена.
- `$count` - необязательная переменная, в которую записывается количество выполненных замен.
- Возвращает новую строку; исходная строка не изменяется.

_Пример_

```php
<?php

$template = 'Здравствуйте, {name}! Ваш заказ {order} принят.';

echo str_replace(
    ['{name}', '{order}'],
    ['Ана', '#1024'],
    $template
);
// Здравствуйте, Ана! Ваш заказ #1024 принят.
```

### Форматирование чисел

_Синтаксис_

```php
number_format(float $num, int $decimals = 0, ?string $decimal_separator = ".", ?string $thousands_separator = ","): string
```

- `$num` - форматируемое число.
- `$decimals` - количество знаков после запятой; число округляется до этой точности.
- `$decimal_separator` - разделитель дробной части.
- `$thousands_separator` - разделитель групп разрядов.
- Возвращает строку.

_Пример_

```php
<?php

echo number_format(14999.5);               // 15,000
echo number_format(14999.5, 2);            // 14,999.50
echo number_format(14999.5, 2, ',', ' ');  // 14 999,50
```

Первая строка показывает, что без указания точности число округляется до целого. Значения по умолчанию соответствуют англоязычной записи чисел, поэтому для принятой в Молдове записи разделители указываются явно.

## Практический пример. Разработка каталога MiniShop с использованием функций

В главе 4 фрагмент каталога MiniShop был реализован без функций: отбор, сортировка и вычисление стоимости остатков были записаны непосредственно в теле страницы. Перепишем тот же фрагмент, оформив каждое действие отдельной функцией.

```php
<?php

declare(strict_types=1);

$products = [
    ['id' => 1, 'name' => 'Ноутбук Lenovo IdeaPad 3', 'price' => 14999, 'stock' => 3],
    ['id' => 2, 'name' => 'Мышь Logitech M185', 'price' => 299, 'stock' => 0],
    ['id' => 3, 'name' => 'Монитор Dell P2422H', 'price' => 3499, 'stock' => 12],
    ['id' => 4, 'name' => 'Клавиатура Keychron K2', 'price' => 1899, 'stock' => 5],
];

function formatPrice(int $price): string
{
    return number_format($price, 0, ',', ' ') . ' лей';
}

function filterInStock(array $products): array
{
    $available = array_filter($products, fn (array $p): bool => $p['stock'] > 0);

    return array_values($available);
}

function sortByPrice(array $products): array
{
    usort($products, fn (array $a, array $b): int => $a['price'] <=> $b['price']);

    return $products;
}

function stockValue(array $products): int
{
    $values = array_map(fn (array $p): int => $p['price'] * $p['stock'], $products);

    return array_sum($values);
}

$catalog = sortByPrice(filterInStock($products));

?>
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>MiniShop - каталог</title>
</head>
<body>
    <h1>Каталог</h1>

    <p>В наличии товаров: <?= count($catalog) ?> из <?= count($products) ?></p>

    <table>
        <tr>
            <th>Товар</th>
            <th>Цена</th>
            <th>Остаток</th>
        </tr>
        <?php foreach ($catalog as $product): ?>
            <tr>
                <td><?= $product['name'] ?></td>
                <td><?= formatPrice($product['price']) ?></td>
                <td><?= $product['stock'] ?> шт.</td>
            </tr>
        <?php endforeach; ?>
    </table>

    <p>Стоимость остатков: <?= formatPrice(stockValue($catalog)) ?></p>
</body>
</html>
```

## Типичные ошибки

### Обращение к внешней переменной из функции

```php
<?php

$currency = 'лей';

function formatPrice(int $price): string
{
    return $price . ' ' . $currency;
}

echo formatPrice(299);   // Warning: Undefined variable $currency
```

Значение передаётся параметром или объявляется константой.

### Ожидание, что функция изменит переданный массив

```php
<?php

declare(strict_types=1);

function addToCart(array $cart, string $item): array
{
    $cart[] = $item;

    return $cart;
}

$cart = [];
addToCart($cart, 'Мышь');   // результат не присвоен
echo count($cart);          // 0
```

Результат функции необходимо присвоить: `$cart = addToCart($cart, 'Мышь');`.

### Вывод вместо возврата значения

```php
<?php

function total(array $prices): void
{
    echo array_sum($prices);
}

$sum = total([100, 200]);   // выводит 300, но $sum равно null
```

### Подсчёт длины кириллической строки функцией strlen()

```php
<?php

$name = 'Ана';

if (strlen($name) > 5) {
    echo 'Имя слишком длинное';   // выполнится: strlen() вернула 6
}
```

Для строк в UTF-8 используется `mb_strlen()`.

### Ожидание непрерывной нумерации после array_filter()

```php
<?php

declare(strict_types=1);

$prices = [299, 14999, 3499];

$expensive = array_filter($prices, fn (int $p): bool => $p > 1000);

echo $expensive[0];
// Warning: Undefined array key 0; массив содержит ключи 1 и 2
```

Функция `array_filter()` сохраняет исходные ключи. Для получения нумерации с нуля результат обрабатывается функцией `array_values()`.

## Резюме

1. Функция - именованный блок кода, который принимает данные через параметры и возвращает результат оператором `return`; функция без `return` возвращает `null`.
2. Параметр объявляется в заголовке функции, аргумент передаётся при вызове; начиная с PHP 8 аргумент можно передать по имени параметра.
3. Функции, вычисляющие данные, возвращают результат, а не выводят его; вывод выполняется в шаблоне.
4. Аргументы, включая массивы, передаются по значению; изменения переменной вызывающего кода передаются обратно возвратом результата или, реже, передачей по ссылке.
5. Объявления типов описывают контракт функции, а директива `declare(strict_types=1)` отключает автоматическое приведение и обнаруживает неверный вызов в месте его совершения.
6. Переменные внешней области внутри функции недоступны; данные передаются параметрами, а неизменные значения объявляются константами.
7. Анонимная функция получает доступ к внешним переменным через `use`, стрелочная функция захватывает их автоматически; обе используются как callback-функции.
8. Функции `array_map()`, `array_filter()` и `usort()` покрывают преобразование, отбор и сортировку массивов по произвольному правилу; `array_filter()` сохраняет исходные ключи.
9. Строка PHP является последовательностью байтов, поэтому для текста в UTF-8 используются функции с префиксом `mb_`.
