# Примеры к обновлённым разделам

- `06_same_file/index.php` - форма и обработка в одном файле.
- `07_shared_context/index.php` и `form.php` - обработка с подключением формы в одном запросе.
- `08_separate/form.php` и `handler.php` - форма и отдельный обработчик.
- `contact/index.php`, `handler.php` и `functions.php` - итоговая форма с проверками и выводом ошибок (требуется `mbstring`).
- `minishop.php` - предварительный расчёт стоимости товара MiniShop.

Файлы предназначены для запуска через веб-сервер с PHP 8. Откройте соответствующий `index.php`, `form.php` или `minishop.php` в браузере через адрес сервера.

Здесь собраны примеры к заменённому разделу об организации кода, итоговая форма с валидацией и добавленный MiniShop. Пути `../_samples/...` и `../_images/...` в главе относятся к исходному проекту курса.
